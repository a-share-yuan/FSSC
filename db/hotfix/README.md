# db/hotfix/ — 单环境数据修正

放「某个环境的数据被写坏／演练留下脏状态，但没有界面可改」这类一次性修正脚本。
和 `db/upgrade/` 的区别：那边是**版本级**结构与种子变更，这边是**数据级**定点修复，不随版本走。

每个文件成对提供 `*_rollback.sql`，脚本都写成幂等（带状态条件，重复执行影响 0 行）。

| 日期 | 脚本 | 现象 | 影响行 |
| --- | --- | --- | --- |
| 2026-11-05 | `20261105_bg_item6_unfreeze.sql` | 差旅费·BG202611（`bg_item.id=6`）在 11-03 冻结演练后遗留 `freeze=1`，前端只有「冻结」没有「解冻」，事前申请被「预算行已冻结」拦下 | 1 行 |

执行方式：

```bash
mysql -uroot -p --default-character-set=utf8mb4 fssc < db/hotfix/20261105_bg_item6_unfreeze.sql
```

> `db/Dump20261104/` 已同步修正该行（`freeze=0`），新导入的环境不会复现；
> 本脚本只用于**已经在跑、不想重导**的环境。
