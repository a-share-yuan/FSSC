## 2. 四道防线实现清单

| 防线 | 类 | 说明 |
|---|---|---|
| ① 身份防线 | `JwtAuthFilter`(Order1) + `TokenService` + `LoginUser`/`UserContext` | tenantId 只来自**已验签 Token**，系统不存在 X-Tenant-Id 请求头；两级路由校验（/api/platform/** 仅 PLATFORM） |
| ② 状态防线 | `TenantFilter`(Order2) + `TenantStatusValidator`(可插拔) | 校验租户冻结/过期/注销；P1 用默认放行实现，P2 换 DB 实现 |
| ③ 权限防线 | `PermissionAspect` + `@RequiresPerm`/`@RequiresFeature`/`@PlatformOnly`/`@DataScope` | 权限码 ∩ 功能码；data_scope 多角色取最宽、查不到默认 5 |
| ④ 数据防线 | `MybatisPlusConfig` + `FsscTenantLineHandler` | 所有业务表 SQL 自动追加 `tenant_id = ?`；忽略表：pf_* / sys_menu / sys_dict_*_def / ACT_* / FLW_* |

### 2.1 拦截器顺序（高危坑）
```java
interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(handler)); // ① 先
interceptor.addInnerInterceptor(new PaginationInnerInterceptor(MYSQL));   // ② 后
```
反了 → count 语句不带 tenant_id，列表是本租户数据、总数却是全库的（泄露数据规模）。

### 2.2 fail-closed
`TenantContext.getTenantId()`：`ignore=false` 且 `tenantId=null` 时抛 `4010 租户上下文缺失`。
- 平台端上下文 = `tenantId=null, ignore=false`（pf_* 靠忽略表白名单放行；平台误查业务表 → 直接抛异常）。
- 跨租户聚合 = `runIgnoreTenant()` 显式开洞（只允许 count/sum）。

### 2.3 认证时序死锁解法
`JwtAuthFilter` 从**已验签 Token** 解析 tenantId 后直接 `TenantContext.set(tenantId)` 建立上下文，
不依赖任何请求头，也不需要把 sys_user 加进忽略表。

## 4. 本轮抓到的坑（已修复，皆真实环境复现）

1. **Git Bash 无法启动 `mvn`**（classworlds ClassNotFoundException）：POSIX 路径传给 Windows java 失效。
   → 封装 `scripts/mvn.py`（os.getcwd() 拿 Windows 原生路径 + 直接 classworlds 启动），统一编译入口。
2. **Lombok getter 全部缺失**：JDK 26 javac 默认不再从 classpath 发现注解处理器。
   → 父 POM 显式 `annotationProcessorPaths` + `<proc>full</proc>`。
3. **MP 3.5.9 找不到 TenantLineHandler / net.sf.jsqlparser**：3.5.9 把租户/分页拦截器与 jsqlparser
   拆到 `mybatis-plus-jsqlparser` 独立模块，starter 不携带，必须显式引入。
4. **类名自遮蔽**：自定义 `MetaObjectHandler`/`TenantLineHandler` 与 MP 接口同名 → 循环继承/自我定义。
   → 重命名 `FsscMetaObjectHandler`/`FsscTenantLineHandler`。
5. **`characterEncoding=utf8mb4` 被 Connector/J 9.x 拒绝**（Unsupported character encoding）：
   旧驱动容忍，9.1.0 严格校验。→ 改为 `characterEncoding=UTF-8&connectionCollation=utf8mb4_general_ci`。
6. **过滤器抛的 BizException 变 500**：@RestControllerAdvice 只管 Controller 调用链。
   → 新增 `FrameworkErrorRenderer`，JwtAuthFilter/TenantFilter catch 后直接渲染 JSON（HTTP 200 + body.code）。
7. **启动端口随机**：环境变量 `SERVER__PORT=0` 被 Spring relaxed binding 识别为 server.port=0。
   → `run-server.sh` 显式 `--server.port` 覆盖；本机 8080 被其他服务占用，默认改用 18080。

## 5. 如何运行

```bash
# 1. 建库（P0 已交付，本机已建）
# 2. 编译 + 打包
python scripts/mvn.py -q package -DskipTests
# 3. 启动（默认 18080）
bash scripts/run-server.sh --port 18080
# 4. 冒烟验证
curl -X POST http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","subjectType":"TENANT","tenantId":1,"dataScope":1,"perms":"demo:secret","features":"F_DEMO"}'
# 拿 token 后：/api/tenant/demo/me | /users | /userCount | /secret
```
