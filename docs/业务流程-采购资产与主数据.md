# 业务流程：采购、资产与主数据

采购是应付链的上游，资产存货是"东西"的账，主数据（`md_*` 53 张表）是
一切配置的地基。本篇把三者放在一起，因为它们共同的特点是"配置驱动"。

## 1. 采购流程

```
[采购申请] → [采购订单 po_order] → [收货 po_receipt] → [三单匹配(见应付篇)]
                                              ↓
                                    [退货 pur_return]（逆向）
```

- 订单行（`po_order_line`）带物料/数量/单价/税率，是匹配的基准；
- 收货可分批，未齐套订单在应付侧挂起；
- 退货走逆向流程，红冲订单/收货/发票三腿联动。

## 2. 资产存货

### 2.1 资产（asset 域）
- 资产主数据（`md_asset`）：类别/原值/寿命/折旧方法；
- 折旧批次（`md_asset_depr_detail`）：按月计提，生成总账凭证；
- 资产变动（`md_asset_change_log`）：调拨/减值/报废全程留痕。

### 2.2 存货（stock/md_inventory）
- 出入库（`stock_move`）、成本结转（`stock_cost_settle`）；
- 与采购收货、销售出库（`so_shipment`）联动。

## 3. 主数据治理（md_* 53 张表）

### 3.1 主数据清单（按用途）

| 分组 | 代表表 |
|---|---|
| 组织 | `sys_company`/`sys_dept`/`md_cost_center`/`md_project` |
| 财务 | `md_subject`/`md_currency`/`md_exchange_rate`/`md_bank`/`md_bank_account` |
| 客商 | `crm_customer`/`md_supplier`(+`_bank`/`_contact`/`_qualification`) |
| 费用 | `md_expense_item`/`md_expense_standard`/`expense_policy*` |
| 业务配置 | `md_io_template`/`md_print_template*`/`md_form_field`/`md_form_validation` |
| 流程 | `wf_flow_config`/`wf_process_config`/`md_period`（会计期间） |

### 3.2 治理原则
- **字典按域建**：同一码在不同域含义不同（`IN` 在现金流量码=流入、收支=收入），
  跨域复用必出展示错乱；
- **元数据反射生成**：表单字段/校验规则由表结构反射生成（`md_form_field`），
  不手写字段列表——元数据与物理表逐字对得上；
- **模板入库**：打印套打（毫米坐标）、导入导出（解释器执行）都是数据不是代码，
  运营改模板不发版。

### 3.3 变更纪律
- 主数据变更走审批（特别是银行账户/客商开户信息）；
- 演示库的客商/银行数据**已脱敏**（虚构名 + `622202` 虚构账号），
  生产数据严禁打进开发库。

## 4. 排障速查

| 现象 | 先查 |
|---|---|
| 下拉选项不对 | 域字典 vs 展示字典取词口径 |
| 打印串位 | 打印模板毫米坐标 + 数据绑定字段 |
| 导入报错一片 | 导入模板解释器的逐行错误清单（不是整批失败） |
| 表单校验不生效 | `md_form_validation` 规则是否随表结构刷新 |
