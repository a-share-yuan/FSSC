## 8. 人工核验指引（模拟数据落库后如何逐页核对）

1. **域覆盖**：对每个贯通域，打开其菜单页面，确认列表非空、且与本手册第6节流程角色一致。
2. **角色一致性**：审批待办（wf_task）的 `assignee` 必须来自第6节节点解析出的真实用户；不可出现手册外用户名。
3. **公司/部门外键**：每张业务单据的 `company_id`/`dept_id` 必须 ∈ 第1/2节清单。
4. **凭证-付款闭环**：费用报销 → 占用预算(bg_occupy) → 影像(img_batch) → 发票(inv_invoice) → 共享凭证(op_voucher/op_gl_entry) → 付款(op_pay_batch) → 银行流水(op_bank_statement) → 档案(op_archive)，逐环可追溯同一 `biz_no`。
5. **回滚**：所有模拟数据落库脚本均产出 `_rollback_*.json`，可逆向删除。
