## 4. 报销主线（核心演示场景）

### 场景 A：员工差旅报销全链路（含借款核销 + 凭证 + 共享作业 + 付款）

**Step 1 发起报销**
1. 以 `bob`（DEMO1）登录 → 费用报销 → 发起报销 → 差旅培训报销
2. 填：标题、公司/部门、费用明细（费用项=差旅费、金额、日期、成本中心）、上传发票影像（见第 8 节）
3. 保存草稿 → **预期**：出现在"保存草稿"列表，状态 DRAFT，不产生流程
4. 提交 → **预期**：进入审批流，生成流程实例与待办

**Step 2 逐级审批**
1. 以 `alice` 登录 → 审批工作台 → 看到待办（标题含单据号）
2. 审批 → 同意 → **预期**：流转到下一节点；同时消息中心收到"审批待办提醒"（站内信，见第 11 节）
3. 逐级审批到通过 → **预期（自动发生）**：
   - 单据状态 APPROVED
   - 预算占用确认（若有预算）
   - **凭证自动生成**（报销单 → 借贷分录）
   - 共享作业链自动入池（票据审核 → 付款审核 → 记账归档，首环节 WAITING）
   - 若有借款：自动核销借款余额

**Step 3 查看凭证**
1. 费用报销 → 我的单据 → 该单 → 「凭证」tab
2. **预期**：显示凭证号/借贷分录（科目已解析）；「打印凭证」可套打

**Step 4 共享作业处理**
1. 共享运营 → 共享作业池 → 认领「票据审核」→ 完成 → **预期**：自动激活下一环节「付款审核」→ 认领完成 → 「记账归档」→ 完成 → 单据入待归档

**Step 5 付款**
1. 资金管理 → 出纳付款 → **预期**：页面自动组批（该单付款记录 WAITING 按收款方归组）
2. 批次 → 查看明细 → 确认 → **预期**：状态 CONFIRMED → 执行付款 → **预期**：批次 PAID、付款记录 PAID、单据 paid_amount 累加
3. 银企对账（见第 7 节）可勾到该笔流水

**Step 6 归档**
1. 档案归档（或等待每天 2:00 自动归档）→ **预期**：单据 ARCHIVED、生成档案记录、影像迁移 archive 区

### 场景 B：事前申请 → 转报销（会议）
1. `bob` → 费用报销 → 事前申请 → 会议申请 → 填预计金额 → 提交 → `alice` 审批通过
2. 该申请单 → 「转报销」→ **预期**：自动生成报销单草稿并带出申请信息/金额
3. 报销单补充发票 → 提交审批 → 走场景 A 后续链路

### 场景 C：借款 → 还款闭环
1. `bob` → 借款还款 → 借款申请 → 金额 5000 → 提交 → 审批通过
2. **预期**：`bob` 借款余额 +5000；若超借款额度配置 → 拦截
3. 还款管理 → 还款单（关联借款）→ 金额 5000 → 审批通过
4. **预期**：借款余额归零（核销），生成还款凭证

## 5. 预算管理（占用与拦截）

### 5.1 建立预算
1. 预算管理 → 预算期间（2026-08）→ 预算方案 → 编制科目（如差旅费 10000）→ 预算组织绑定
2. **预期**：占用查询可见该科目可执行金额

### 5.2 占用与拦截
1. `bob` 提交差旅报销 8000 → 审批通过 → **预期**：预算占用 +8000（可执行余额 2000）
2. 再提交差旅报销 3000 → **预期**：超预算拦截或标记（取决于配置）
3. 驳回该单 → **预期**：占用自动释放

### 5.3 预算调整
1. 预算管理员 → 预算调整 → 调增差旅费 5000 → **预期**：占用后可执行金额变化正确

## 6. 购销三单匹配（对公付款核心闭环）

### Step 1 采购订单
1. 购销管理 → 采购订单 → 新增：`PO-DEMO-01`、供应商=北京华信、金额 20000 → 保存
2. **预期**：列表出现，剩余可收 20000

### Step 2 收货单（挂 PO）
1. 购销管理 → 收货单 → 新增：收货单号、选择 PO-DEMO-01 → 自动带出供应商 → 金额 8000 → 保存
2. **预期**：PO 累计收货回写 8000、剩余 12000；收货单状态 RECEIVED
3. **拦截测试**：再建收货单金额 15000（> 剩余 12000）→ **预期**：报"收货超订单：剩余可收 12000 < 本次收货 15000"

### Step 3 供应商对账
1. 购销管理 → 供应商对账 → 选择供应商+期间 → 生成对账单
2. **预期**：显示 应付合计（该供应商发票）/已付合计/余额；有差异则余额非 0（如多付/少付）
3. 与供应商核对 → 「确认一致」→ **预期**：状态 CONFIRMED（差异则「标记差异」填说明）

### Step 4 对公付款单（关联三单）
1. 费用报销 → 对公支付 → 对公结算 → 往来单位=北京华信 → **预期**：自动加载该供应商未执行完的 PO
2. 选「采购订单」PO-DEMO-01、选「收货单」GRN（自动带 PO）→ 金额 8000 → 提交 → 逐级审批通过
3. **预期**：付款记录自动生成（WAITING）

### Step 5 三单匹配检查
1. 共享运营 → 对公三单匹配 → 找到该付款单
2. **预期**：列显示 PO 号/收货单/关联发票/本次付款 + 匹配状态：
   - 发票合计 ≥ 付款 → 三单一致 MATCHED（绿色）
   - 发票 < 付款 → **超付 FAILED（红色，付款批次执行将被硬拦截）**
   - 未关联收货/发票 → WARN（黄色，附具体原因）
   - 供应商对账未确认 → 提示"供应商对账未确认"
3. **拦截测试**：发票不足时执行付款批次 → **预期**：报"三单匹配拦截：付款单 XX 超付，禁止执行付款"

### Step 6 出纳付款
1. 资金管理 → 出纳付款 → 自动组批 → 确认 → 执行 → 回写（同场景 A Step 5）

## 7. 资金管理与银企对账

### 7.1 银行流水
1. 资金管理 → 银行流水 → 导入（从网银导出的流水文件，含银行流水号/方向/金额/余额/对方户名）
2. **预期**：流水入 op_bank_statement，recon_status 为空

### 7.2 自动勾对
1. 银企对账 → 立即勾对（或等待定时任务）
2. **预期**：流水号/金额+账号匹配到付款记录的 → MATCHED 并留痕；未匹配的保持 UNRECON

### 7.3 未达账项调节表
1. 共享运营 → 未达账项调节表 → 选账户+月份 → 生成
2. **预期**：四宫格（银行对账单余额/调节后余额/企业账面余额/调节差）+ 三类未达项明细：
   - 银行已收企业未收（CREDIT 流水未勾对）
   - 银行已付企业未付（DEBIT 流水未勾对）
   - 企业已付银行未付（PAID 付款无勾对记录）
3. 调节差=0 → 已平；非 0 → 待查（指向差异在哪）

## 8. 影像管理与发票（OCR 全自动）

### 8.1 上传影像
1. 影像管理 → 影像任务 → 创建批次（绑定单据）→ 上传发票图片
2. **预期（自动）**：上传后**自动触发 OCR**（无需手动点识别）→ 页面状态 NONE→PENDING→SUCCESS；失败显示 FAILED（可手动重试）

### 8.2 发票生成与验真
1. 识别成功 → **预期**：自动生成 inv_invoice（发票代码/号码/价税分离 amount=net+tax）
2. 发票管理 → 发票池 → **预期**：新发票出现；验真定时任务（每 5 分钟）自动更新验真状态
3. 重复发票测试：录入相同发票代码+号码 → **预期**：唯一键拦截（uk_tenant_inv）

### 8.3 单据绑定发票
1. 报销/付款单详情 → 绑定发票 → **预期**：inv_bill_invoice 关联、三单匹配发票侧金额随之变化

## 9. 共享运营作业链（抢单式）

1. 任意报销单审批通过后 → 共享运营 → 作业池出现「票据审核」（WAITING，可认领）
2. 认领 → 处理 → 完成 → **预期**：自动激活下一环节「付款审核」→ 完成 → 「记账归档」→ 完成
3. 调阅评价/异常处理：影像不完整单据 → 异常处理 → **预期**：回退或标记，不影响其他单据

---

## 10. 合同管理

1. 合同管理 → 合同台账 → 新增合同（合同号/双方/金额/期间）→ 保存
2. 对公付款选择"付款合同"时 **预期**：下拉显示该往来单位未执行完毕合同及剩余额度（金额-已付）
3. 合同付款查询 → **预期**：按合同汇总已付/剩余

---

## 11. 通知多渠道（站内/企微/邮件）

1. 系统配置 → 全局参数 → 搜索 `notify` → 配置：
   - `notify.wecom_webhook`：企业微信群机器人地址（群设置→群机器人→添加）
   - `notify.mail.host/port/username/password/from`：SMTP（host 留空则邮件仅记日志）
2. 给用户填邮箱（用户管理）
3. 提交一张单据 → 审批人立即收到：
   - **站内信**（必达）：消息中心/公告消息
   - **企微**（配置了 webhook）：群消息推送
   - **邮件**（用户有邮箱）：日志可见 `[邮件通知-模拟]`
4. **预期**：修改配置**立即生效**（无需重启）

## 12. 管理报表

1. 管理报表 → 报表聚合 → **预期**：月度聚合自动（每天 1:30）或手动刷新生成
2. 看板（工作台）→ **预期**：单据量/金额趋势、待办统计（按月聚合，期间维度）
3. 系统监控 → 系统日志/运行状态 → **预期**：操作日志（含审计留痕）、运行健康信息

## 13. 异常与边界（回归必测清单）

| # | 场景 | 操作 | 预期 |
|---|---|---|---|
| 1 | 驳回 | 审批驳回 | 单据回退、预算占用释放、申请人生成修改待办 |
| 2 | 撤回 | 提交后撤回 | 流程终止、状态回草稿 |
| 3 | 作废 | 作废草稿/单据 | 状态 VOID、不再参与任何统计 |
| 4 | 超标准 | 差旅超标准 | 审批页标记 overStd + 原因 |
| 5 | 缺发票 | 报销必须附发票项无发票 | 提交被拦截 |
| 6 | 超借款额度 | 借款超额度 | 提交被拦截 |
| 7 | 收货超单 | 收货 > PO 剩余 | 拦截 |
| 8 | 三单超付 | 发票 < 付款 | 匹配 FAILED + 付款执行拦截 |
| 9 | 重复发票 | 相同发票代码+号码 | 唯一键拦截 |
| 10 | 同名账号 | DEMO1/DEMO2 的 alice | 各自独立登录、互不可见 |
| 11 | 无租户上下文 | token 失效/未带 | 401，重新登录 |
| 12 | 打印 | 单据/凭证套打 | 新窗口标准格式 + 签字行 |
| 13 | 对账差异 | 对账单余额≠0 | 标记差异留说明，可再生成覆盖 |
