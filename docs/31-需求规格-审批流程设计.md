# 财务共享平台审批流程设计规范

> 基于《财务共享平台-AI开发需求文档.md》整理
> 本文档汇总所有业务模块的审批流程设计，供开发参考

---

## 审批流程总体架构

### 审批流程层级

```
单据提交 → 预算检查 → 业务审批（多级） → 财务审核 → 记账/支付
```

### 审批人角色体系

| 角色 | 说明 | 审批规则 |
|-----|------|---------|
| 直接主管 | 经办人直属上级 | 必选 |
| 部门经理 | 部门负责人 | 金额在阈值内时可选 |
| 分管领导 | 公司分管副总 | 超阈值时必选 |
| 财务审核岗 | 共享中心审核员 | 所有单据必经 |
| 财务经理 | 共享中心负责人 | 特定类型单据必经 |

### 审批分支条件

| 条件维度 | 分支规则 |
|---------|---------|
| 金额阈值 | ≤10000→直接主管；10000-50000→部门经理；>50000→分管领导 |
| 费用类型 | 招待费、会议费等特殊类型额外审批 |
| 费用承担类型 | 项目承担→项目经理审批；成本中心承担→部门经理审批 |
| 人员级别 | 高管→额外审批流程 |
| 业务类型 | 境内/境外、项目/非项目等不同流程 |

## 一、事前申请类审批流程

### 1.1 会议申请审批流程

**适用范围**：所有会议费用的事前申请

| 序号 | 流程节点 | 审批人 | 触发条件 | 审批动作 |
|-----|---------|-------|---------|---------|
| 1 | 预算检查 | 系统自动 | 提交时 | 占用预算/超预算拒绝 |
| 2 | 直接主管审批 | 经办人直属上级 | 金额≤10000 | 同意/退回/拒绝 |
| 3 | 部门经理审批 | 部门负责人 | 金额>10000 或 项目承担 | 同意/退回/拒绝 |
| 4 | 分管领导审批 | 公司分管副总 | 金额>50000 | 同意/退回/拒绝 |
| 5 | 预算管理员备案 | 预算管理员 | 所有单据 | 查看/备案 |

**分支条件**：
- 项目承担：增加项目经理审批节点
- 成本中心承担：直接进入部门经理审批

**流程图**：
```
经办人填制 → 提交 → 预算检查
                        │
                        ▼
               ┌────────┴────────┐
               ▼                 ▼
          [项目承担]         [成本中心承担]
               │                 │
               ▼                 ▼
          项目经理审批       直接主管审批
               │                 │
               ▼                 ▼
          部门经理审批 ◄──────────┘
               │
               ▼
       ┌─────金额>50000─────┐
       ▼                    ▼
  分管领导审批           [跳过]
       │                    │
       ▼                    ▼
     预算管理员备案
```

### 1.2 出差申请审批流程

**适用范围**：员工出差事前申请

| 序号 | 流程节点 | 审批人 | 触发条件 | 审批动作 |
|-----|---------|-------|---------|---------|
| 1 | 预算检查 | 系统自动 | 提交时 | 占用预算/超预算拒绝 |
| 2 | 差旅标准检查 | 系统自动 | 提交时 | 超标准需填写原因 |
| 3 | 直接主管审批 | 经办人直属上级 | 国内出差 | 同意/退回/拒绝 |
| 4 | 部门经理审批 | 部门负责人 | 金额>5000 或 国外出差 | 同意/退回/拒绝 |
| 5 | 分管领导审批 | 公司分管副总 | 金额>20000 或 高管出差 | 同意/退回/拒绝 |
| 6 | HR考勤同步 | 系统自动 | 审批通过后 | 推送出差日期到HR |
| 7 | 商旅平台推送 | 系统自动 | 审批通过后 | 推送行程到商旅 |

**分支条件**：
- 出差类型：国内/三地→简化流程；国外→增加安全审批
- 超标处理：超标需直接主管和部门经理双重审批

**流程图**：
```
经办人填制 → 提交 → 预算检查+差旅标准检查
                              │
                   ┌──────────┴──────────┐
                   ▼                     ▼
            [国内/三地]              [国外出差]
                   │                     │
                   ▼                     ▼
            直接主管审批            直接主管审批
                   │                     │
          ┌────────┴────────┐            │
          ▼                 ▼            ▼
     [金额≤5000]      [金额>5000]  部门经理审批
          │                 │            │
          │                 ▼            ▼
          │           部门经理审批   ┌────金额>20000────┐
          │                 │       ▼                  ▼
          │                 │   分管领导审批         [跳过]
          │                 │       │                  │
          └─────────────────┴───────┴──────────────────┘
                            │
                            ▼
                    HR/商旅平台同步
```

## 二、员工报销类审批流程

### 2.1 员工费用报销审批流程

**适用范围**：员工日常费用报销

| 序号 | 流程节点 | 审批人 | 触发条件 | 审批动作 |
|-----|---------|-------|---------|---------|
| 1 | 事前申请关联检查 | 系统自动 | 提交时 | 按费用类型判断是否需关联申请 |
| 2 | 预算扣减检查 | 系统自动 | 提交时 | 扣减预算/超预算拒绝 |
| 3 | 发票验真检查 | 系统自动 | 提交时 | 发票已验真/异常发票处理 |
| 4 | 直接主管审批 | 经办人直属上级 | 所有单据 | 同意/退回/拒绝 |
| 5 | 部门经理审批 | 部门负责人 | 金额>3000 或 超标费用 | 同意/退回/拒绝 |
| 6 | 财务审核 | 财务审核岗 | 所有单据 | 同意/退回/调整 |
| 7 | 财务记账 | 系统/财务 | 审核通过后 | 生成凭证/人工调整 |
| 8 | 支付处理 | 资金岗 | 记账后 | 执行支付 |

**分支条件**：
- 超标费用：超标需直接主管审批+财务审核
- 借款冲销：有借款的报销自动冲销
- 特殊费用：招待费、会议费需额外审批

**流程图**：
```
经办人填制 → 提交
                 │
    ┌────────────┼────────────┐
    ▼            ▼            ▼
 申请关联    预算检查    发票验真
    │            │            │
    └────────────┼────────────┘
                 │
                 ▼
         直接主管审批
                 │
        ┌────────┴────────┐
        ▼                 ▼
   [金额≤3000]       [金额>3000/超标]
        │                 │
        │                 ▼
        │           部门经理审批
        │                 │
        └────────┬────────┘
                 │
                 ▼
            财务审核
                 │
                 ▼
            财务记账
                 │
                 ▼
            支付处理
```

## 三、对公支付类审批流程

### 3.1 费用预付款申请审批流程

**适用范围**：对公预付款（非PO费用类合同预付款等）

| 序号 | 流程节点 | 审批人 | 触发条件 | 审批动作 |
|-----|---------|-------|---------|---------|
| 1 | 合同关联检查 | 系统自动 | 提交时 | 按往来单位匹配未执行完合同 |
| 2 | 预算检查 | 系统自动 | 提交时 | 预算冻结/超预算拒绝 |
| 3 | 资金计划检查 | 系统自动 | 提交时 | 资金计划校验 |
| 4 | 部门经理审批 | 费用归属部门负责人 | 所有单据 | 同意/退回/拒绝 |
| 5 | 财务经理审批 | 共享中心负责人 | 金额>50000 | 同意/退回/拒绝 |
| 6 | 财务记账 | 系统/财务 | 审批通过后 | 生成凭证 |
| 7 | 支付处理 | 资金岗 | 记账后 | 执行支付 |
| 8 | 合同支付更新 | 系统自动 | 记账后 | 更新合同支付信息 |

**分支条件**：
- 关联合同：记账后自动更新合同已支付金额
- 非关联合同：直接进入支付流程

**适用范围**：已取得发票的非PO类对公支付结算

## 附录：审批流程配置建议

### A. 金额阈值配置

| 审批层级 | 金额阈值（建议） | 可配置 |
|---------|----------------|-------|
| 直接主管 | 0-10,000 | ✓ |
| 部门经理 | 10,000-50,000 | ✓ |
| 分管领导 | 50,000+ | ✓ |
| 财务经理 | 100,000+ | ✓ |

### B. 超时处理规则

| 场景 | 超时时间 | 处理方式 |
|-----|---------|---------|
| 直接主管审批 | 24小时 | 自动升级至部门经理 |
| 部门经理审批 | 48小时 | 自动升级至分管领导 |
| 财务审核 | 4小时 | 自动分配至备用审核岗 |
| 支付处理 | 8小时 | 通知资金负责人 |

### C. 审批动作定义

| 动作 | 说明 | 后续状态 |
|-----|------|---------|
| 同意 | 同意单据 | 流转到下一节点 |
| 退回 | 退回给制单人 | 制单人修改后重新提交 |
| 拒绝 | 拒绝单据 | 单据状态变为"已拒绝" |
| 转办 | 转办给他人 | 被转办人继续审批 |
| 加签 | 增加审批人 | 增加临时审批节点 |
| 减签 | 减少审批人 | 跳过某些审批节点 |

### D. 与外部系统集成点

| 集成系统 | 交互内容 | 触发时机 |
|---------|---------|---------|
| HR系统 | 员工信息、部门、考勤 | 审批流程初始化/出差申请审批通过 |
| IFS系统 | 项目、成本中心、预算数据 | 单据填制时/预算检查时 |
| NC系统 | 项目、科目数据 | 单据填制时 |
| 商旅平台 | 机票/酒店预订信息 | 出差申请审批通过后 |
| BPM系统 | 审批流引擎 | 所有单据审批时 |
| 银企系统 | 支付执行 | 支付处理时 |
