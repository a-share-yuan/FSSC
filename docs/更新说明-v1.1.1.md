# FSSC v1.1.1 更新说明

发布日期：2026-11-05
版本范围：后端 `fssc-server` / `fssc-common` / `fssc-start` 与前端 `fssc-web` 统一为 **1.1.1**；配套演示库 `db/Dump20261104/` 已刷新。

本版聚焦四条线：**制证科目守卫**、**税务闭环**、**采购与预付**、**报表导航**，并补齐了一批协作体验与深色模式问题。

## 一、制证科目守卫

- 费用项目维护页新增「对应会计科目」下拉，只列出**启用、末级、本公司或租户共用**的科目；保存时逐项校验，配错当场拒绝并说明原因。
- 报销单、对公结算单提交时按费用行预检制证科目：缺配置、已停用、跨公司、父科目都会在提交环节拦下，并点名费用项目与配置入口（【基础资料 › 费用项目】）。
- 自动制证取消 6602「管理费用」兜底。取数顺序为：行科目 → 费用项目映射 → 末级下沉；记账规则配置同样要过末级、停用与跨公司校验。2241 缺失改为明确报错。
- 银行手续费、折旧、薪酬计提、物料领用、汇兑损益分别改挂明细科目（660301、660203、660225、660227、660304）；手工记账分录的借方也不再默认 6602。
- 新增下级科目后，父科目自动置为非末级；制证侧按实际子节点数判定末级，手工改错的末级标记不再放行。

主要落点：`fssc/fssc-server/fssc-start/src/main/java/com/fssc/masterdata/service/PostableSubjectResolver.java`、`.../masterdata/service/ExpenseItemService.java`、`.../sharing/service/VoucherService.java`。

## 二、税务

- **申报**：新增【作废】，草稿与待审批可作废并留审计轨迹；已申报、已缴纳只能走更正申报。审批禁止自审——制单人不能审批自己提交的申报单。
- **缴纳登记**：实缴金额必须大于 0；实缴与应纳不一致时，弹窗实时显示差异并二次确认。申报与计提规则表单的必填校验修正，值填对后不再误报「请选择」。
- **退税**：增加过审闸，审批中不能直接跳到「已退税」，须先到「已审批」才能进入「退税中 / 已退税」；界面只列出合法目标状态。申请额或到账额超上限改为提示并回填上限；列表新增申请人、申请时间。
- **风险指标**：属期改为必选，不再默认系统当月；本期无可算数据时作废该属期旧指标并在提示中说明；等级为「正常」时评分固定为 0。

## 三、发票

- 进项转出改为弹窗必填原因（集体福利／个人消费／非正常损失／简易计税／免税项目／其他，可自定义），原因落库，认证列表新增「转出原因」列；只有已勾选发票可转出，未勾选票明确报错而非静默跳过。
- 发票池新增「状态」列（开票审批中／已开具／已驳回／红冲票／已作废等），已驳回票不再与已开具票外观一致。
- 销项开票补齐购方抬头落库；已驳回或草稿发票可按原票号重提，重置为开票审批中并重新发起审批。
- 月度进项、销项发票统计剔除已驳回与已作废发票，报表合计与有效票一致；红冲票保留，靠正负两行自然对冲。

## 四、采购与预付

- 采购订单行「物料编码」改接物料主数据，可按编码或名称检索，选中后自动回填名称与单位，不再用费用项目代替物料。
- 行校验新增「单位必填」，与名称、数量大于 0、单价大于 0、量价勾稽同规则前后端双校验；失败时一次列出全部问题，出错单元格标红可点击定位，并提供「按合计回填订单金额」一键修复。
- 采购订单与退货单弹窗接入脏值守卫：取消、Esc、点击遮罩都需要确认；订单金额与行合计不一致时输入框标红。
- 收货单选中订单即显示「本单最多可收 / 已超出多少」并超限标红；取消前端预拼 GRN 单号，改由服务端取号，避免同一订单第二张收货单重号。退货明细要求名称、数量、单价、单位齐全，未填写的空行不再落库。
- 预付款改用专用三单匹配档：不再因缺收货单、缺发票被冻结；既无合同也无订单判 ERROR，仅有订单时提示补挂合同，核销走【预付冲销】。
- 预付款比例上限由全局参数 `prepay.max.ratio` 控制，缺省 30%，可在【全局参数】按租户调整，置 0 即全部拦截；超限判 ERROR 并冻结，提示给出算式与参数入口。

## 五、月结与总账

- 月结校验清单新增系统判定项「应生成未生成凭证检查」：按单据类型核对本期已办结单据是否已出对应凭证，报出缺凭证张数与示例单号，与「无 DRAFT」判定互补。
- 应付/应收月结、服务申请、协同、应收票据等看板：后端规则拦停时（如「该期间已存在未完成的关账单」「扛数金额为 0」）改为红字提示并保留页面，不再整页跳成「页面出错了」。
- 总账分录台账每行新增【查看】，抽屉直接给出凭证头与借贷两行（与过账权限解耦）；页签条常显，深链单页下也能切到凭证台账等页签。
- 全链路抽屉与请购工作台把「付款批次凭证」（出纳按批次制证）单独列出，明确不计入「记账凭证 N 张」，也不作为费用已入账依据；制证失败时直接显示失败原因与补生成入口。

## 六、报表导航

- 25 张报表按业务归为 8 组：费用报销与预算、应付与采购付款、应收与销售开票、资金与税务、借款、合同、审批与共享运营、记账凭证。菜单按组进入，组内只展开 3～7 个页签，顶部可切组。
- 分组入口路由权限补齐；进项、销项、税负三张发票类报表页签改由 `report:view` 门控，避免税务岗、部门经理进入后整页空白。
- 报表图表在隐藏页签中挂载、切换后也能正确渲染（容器尺寸变化自动重算），不再出现空白图。

主要落点：`fssc/fssc-web/src/views/report/Reports.vue`、`fssc/fssc-web/src/router/routes/finance.js`、`fssc/fssc-web/src/router/routePerms.js`。

## 七、协作与界面

- 新增 `FieldTip` 组件：字段说明从输入框下方灰字收进标签旁的 ⓘ，悬浮或键盘聚焦时显示。已用于审批核减／加签、资产税法折旧年限、委托、差旅预申请、三单容差、采购订单与收货。
- 审批意见输入后直接点【确认】也能提交，等同回车；认领、取消认领后不再弹出错误提示；流转派单优先避开本单已办过节点的人，减少人工转办；委托台账状态角标按分钟自刷新。
- 深色模式：登录页、平台登录与控制台、收藏、骨架屏、关账工作台、总账特殊业务改用主题变量，平台趋势图随主题重建，深色下不再出现白底黑框与看不清的图表文字。
- 管理端：全局参数中 `wf.` 与 `approve.` 前缀参数标为「平台下发·只读」并禁用编辑；无权限的动作不再显示按钮。状态与业务类型补中文（归档中／已归档、已核销、部分收款、已确认坏账、撤回、应付／应收月结、付款计划等），行详情弹窗隐藏创建人、删除标记等技术字段。

### 旧库升级

**不要只跑一条 ALTER。** v1.1.1 要起来需要上表 16 列与 `tax_provision_rule`；而制证守卫还会读「费用项目 → 科目」映射，只加列不补主数据，报销单与对公结算单在**提交**环节就会被拦下（`ExpenseBillService` 提交校验链 → `PostableSubjectResolver.requireExpenseSubject`，报「…未配置对应会计科目，无法制证」）。

- **推荐**：按 `db/README.md` 重导 `db/Dump20261104/`。结构与主数据一起到位，一步到底。
- **必须原地升级**：走 `db/upgrade/`（官方增量脚本，含回滚），顺序是 `V1.6.90_all_in_one` → `V1.6.15`～`V1.6.20` → 停服跑 `V1.6.03` → 换 jar 起服；然后按上一节补齐主数据。脚本覆盖范围与注意事项见 `db/upgrade/README.md`。
- 只想先让库结构对齐（比如先做一次连通性验证）：执行下面的 DDL，再按上一节补数据，最后用文末自检 SQL 核对。
