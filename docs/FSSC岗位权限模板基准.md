> 回滚备份：`fssc/scripts/_rbac_exec_rollback_20260917_180124.json`（重排前全量 4239 条）

## 设计原则

1. **最小权限**：角色权限 = 全员基础包 + 本岗位域包，页面级精确授予。
2. **高危按钮显式授予**：审核类（费用单据审核 3181 / 撤回 3182 / 分摊 3183-3186 / 报表审计阅示 3521）
   与资金付款类（付款批次 3258-3262 / 三单匹配复核 3263 / 付款单 3264-3265）挂在父页面下，
   模板**全局排除**——不随页面连带，只能在模板中用 `btn` 显式授给作业岗。
3. **报表 = 业务域投影**：作业岗按域码持有本域报表；管理层/监督岗为"阅示型"（全域报表 +
   台账查看页），`report:<域>:view` 域码即阅示凭证（接口层 hitForRead 放行，授权卡点仍按业务码把关）。
4. **可重建**：改角色权限 → 改 `TEMPLATE` → 跑 `rbac-execute.py`（全量替换、幂等、自动备份）。
