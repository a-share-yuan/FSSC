# 管理报表

### 11.1 费用发生汇总表
- 统计某层级组织在具体期间段各类费用的发生情况
- 筛选维度：公司、期间、费用类型、记账状态
- 数据权限过滤，支持导出

### 11.2 费用月度变动表
- 统计某特定组织各类费用的月度变动情况

### 11.3 费用构成情况表
- 统计某特定类型费用在各组织的月度变动情况

### 11.4 借款余额汇总报表
- 查询公司下员工的借款金额、未冲销金额明细及汇总

### 11.5 预算执行情况表
- 查询某组织各类型费用每月的预算执行数据

### 11.6 合同汇总表
- 查询某公司下合同的总金额、已付款金额等执行情况

### 11.7 费用明细表
- 通过关键信息查询费用明细数据
- 信息包括：经办人、费用类型、部门、项目、申请单号、申请金额、报销单号、报销金额、报销状态等

### 11.8 运营数据统计表
- 查询共享中心的共享作业情况数据

### UI布局规范说明

#### 1. 页面结构规范
- 每个表单页面分为：标题栏 → 单据概要 → 费用详情 → 分摊信息 → 附加信息 → 底部按钮栏
- 每个区块有标题和"添加信息/删除信息"操作链接
- 区块之间用分隔线区分

#### 2. 表单控件规范
- 下拉选择框（Droplist）：用于选项类字段，如申请人、部门、币别、是否、交通工具等
- 文本框（Text Field）：用于自由输入，如单据说明、超标说明、公司名称
- 日期选择器（Date）：用于日期选择，如出发日期、结束日期
- 金额输入（Number）：用于金额字段，如交通费、住宿费、餐饮补贴
- 表格（Table）：用于分摊信息等明细数据展示
- 文件上传（Upload）：用于附件上传
- 标签页（Dynamic Panel）：用于费用详情中不同费用类型的切换

#### 3. 交互规范
- 表单字段根据费用类型动态显示/隐藏（如税金及发票tab）
- 金额字段自动计算汇总（小计、总额）
- 超标内容自动生成，超标说明在超标时必填
- 分摊信息表格支持添加行、删除行操作
- 费用详情项支持复制、添加、删除操作
- 底部栏显示申请总额、冲销借款、应收报销款

#### 4. 颜色规范
- 标题：加粗，深色
- 金额：橙色(#FF992F/#F59A23)
- 必填字段：带红色*标记
- 禁用字段：灰色背景
- 链接操作：带下划线

#### 5. 布局尺寸
- 页面宽度：1196px
- 区块间距：8-16px
- 行高：34px
- 字体：微软雅黑

## 附录B：通用功能规范

### 1. 列表页面通用功能
- 分页展示、关键字查询、高级筛选
- 导出Excel、刷新
- 单据类型切换
- 状态筛选

### 2. 表单页面通用功能
- 保存（草稿）、提交送审
- 删除（仅草稿/被退回状态）
- 上传附件（支持所有类型文件，可限制大小）
- 单据复制（制单人=当前登录人时可用）
- 申请单关闭/终止报销

### 3. 预算控制通用规则
- 提交时进行预算检查
- 预算充足：正常占用
- 预算不足：柔性控制(预警)/刚性控制(不允许提交)
- 单据关闭/作废：释放预算
- 报销完成：实际扣减预算

### 4. 审批流程通用规则
- 按项目承担/成本中心承担分支
- 按高管/普通员工分支
- 按国内/国外分支
- 按标准内/标准外分支
- 超申请/未超申请分支

### 5. 发票信息通用规则
- 发票类型枚举：增值税专用发票、增值税普通发票、增值税普通电子发票、增值税卷式发票、火车票、汽车票、飞机票、其他可抵扣发票
- 发票信息通过影像系统自动识别+验真，支持手工补录
- 核定税额仅在共享审核界面显示且可修改

### 6. 费用分摊通用规则
- 费用承担类型：成本中心承担、项目承担
- 成本中心承担：需选择成本中心、预算组织、预算类别、预算科目(来源NC)
- 项目承担：需选择项目、预算科目(来源IFS)
- 分摊信息自动带出预算信息提示

### 7. 与外部系统集成
- HR系统：员工信息、部门信息、考勤数据
- 商旅平台：机票/酒店预订信息
- NC系统：预算科目、预算数据
- IFS系统：成本中心、预算科目、项目、记账凭证
- BPM系统：流程审批待办
- 银企系统：支付处理
