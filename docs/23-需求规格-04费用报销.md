# 费用报销设计方案

### 4.1 事前申请类

#### 4.1.1 会议申请

**业务说明**：适用于公司员工在会议活动发生前提交会议申请，填写会议信息、预估费用，进行预算占用。审批通过后可在报销环节引用。

**业务流程**：
| 序号 | 流程节点 | 流程说明 | 参与人 |
|-----|---------|---------|-------|
| 1 | 填制单据 | 操作人费用系统中填制单据，录入相应字段 | 经办人 |
| 2 | 选择项目 | 若是项目费用的申请，需在单据上选择具体的项目 | 经办人 |
| 3 | 匹配项目/部门预算记录 | 根据是否选择项目匹配对应的预算记录 | 系统 |
| 4 | 填写内容提交单据 | 经办人补充完单据内容后提交 | 经办人 |
| 5 | 预算控制流程 | 提交时进行预算检查，通过后占用预算 | 系统 |
| 6 | 业务审批 | 各级领导进行工作流审批 | 业务领导 |
| 7 | 报销流程 | 审批完成的申请单可在报销时引用 | 经办人 |

**系统界面**：
- 表单页面：会议申请单主界面

**页面规则**：
1. 事前申请无需自动生成会计分录
2. 提交时需判定是否超年度预算，超出不允许提交
3. 审批流程根据项目/成本中心承担、是否高管等条件分支
4. **单据复制**：在详情查看界面（已保存/流程中/已完成/财务处理中），当制单人=当前登录人时，显示"复制"按钮，点击后按原单据所有字段值生成新单据
5. **申请单关闭**：已完成状态但未进行报销的申请单可关闭，关闭后释放已占用的预算，状态变为"已关闭"，不能再生成报销单
6. **申请单终止报销**：可多次报销的申请单，后续确定不再报销时可终止，终止后不能再被报销单关联，释放未释放完毕的预算

#### 4.1.2 出差申请

**业务说明**：适用于公司员工日常出差的事前申请，填写出差地点和时间，预估费用金额，占用预算。审批通过后行程信息推送到HR系统（考勤）和商旅系统（票务预订）。报销时根据规则控制是否允许超申请金额报销，并根据差额进行预算补扣与退还。

**业务流程**：
| 序号 | 流程节点 | 流程说明 | 参与人 |
|-----|---------|---------|-------|
| 1 | 填制单据 | 录入相应字段 | 经办人 |
| 2 | 选择项目 | 若为项目费用，选择具体项目 | 经办人 |
| 3 | 匹配项目/部门预算记录 | 系统匹配预算记录 | 系统 |
| 4 | 填写内容提交单据 | 补充内容后提交 | 经办人 |
| 5 | 预算控制流程 | 预算检查、占用 | 系统 |
| 6 | 业务审批 | 各级领导审批 | 业务领导 |
| 7 | 推送行程信息到HR系统 | 审批通过后推送出差日期到HR | 系统 |
| 8 | 推送订票信息到商旅平台 | 如需订票，推送行程到商旅平台 | 系统 |
| 9 | 报销流程 | 完成申请单在报销时引用 | 经办人 |

**系统界面**：
- 主界面：差旅申请单
- 出差人员选择界面：弹窗选择人员

- 列表功能：查询、筛选、查看详情
- 表单功能：新增、复制、删除行程、保存、提交送审、上传附件

**页面规则**：
1. 根据"是否分摊到项目"决定费用分摊至项目还是成本中心
2. 费用分摊区分机票和非机票，机票由行政统一报销，非机票为员工个人报销
3. 强制判断：**同一员工，同期间不允许在多个行程上**
4. 生成分录：无借款无需生成会计分录，有借款需自动生成会计分录，提供财务人员预览和修改的页面
5. 申请时需按不同级别（不同差旅标准）、不同航段拆分填写
6. **提交时判定是否超年度预算**，超出不允许提交
7. **提交时判定是否超差旅标准**，超出需强制填写超标原因
8. 审批流程分支：项目承担/成本中心承担、国内(含三地)/国外、差旅标准内/外、高管/普通员工
9. **出差变更**：针对已完成且未被任何单据关联的申请单，制单人=当前登录用户时可见"出差变更"按钮，点击生成与原单据相同的单据，原单据状态置为作废
10. **生成分摊信息**：点击"生成分摊详情"后，将费用详情中所有费用项按规则生成分摊信息行记录

#### 4.1.3 培训申请

**业务说明**：适用于公司员工培训事项的事前申请，包括无出差的培训以及含出差的培训。申请人和制单人可不一致，支持同时申请多人，培训若涉及出差可将培训及出差一起填报。

**业务流程**：同会议申请基本流程，增加了培训类型判断

**系统界面**：培训申请单

**字段详情**：

**单据概要**：
- 单据编号、制单时间、制单人、申请人(可修改为他人)、申请人部门、申请人公司
- 币种(默认人民币)、总金额、预算费用年度
- 单据说明(必填)、超标内容(自动生成)、超标说明(超标准时必填)

**培训信息**：
| 字段名称 | 录入控制 | 录入方式 |
|---------|---------|---------|
| 预计费用年度 | 必填 | 下拉选择-预算年度 |
| 培训类型 | 必填 | 下拉选择-培训类型 |
| 培训名称 | 必填 | 手工录入 |
| 培训地点 | 必填 | 手工录入 |
| 开始日期 | 必填 | 日期选择 |
| 结束日期 | 必填 | 日期选择 |
| 培训时长 | 必填 | 手工录入 |
| 参与人数 | 必填 | 手工录入 |
| 合计成本 | 自动生成 | 不可编辑 |
| 人均成本 | 自动生成 | 不可编辑 |
| 是否计划内 | 必填 | 下拉选择-是/否 |
| 是否涉及差旅 | 必填 | 下拉选择-是/否 |
| 是否国外出差 | 必填 | 下拉选择-是/否 |
| 备注 | 必填 | 手工录入 |

**培训人员列表及费用详情**：
- 培训人姓名(必填)、开始日期、结束日期、培训天数
- 若涉及差旅：出发地、目的地、出发日期、结束日期、出行方式、舱位等级、是否往返
- 费用项：培训费、长途交通费、住宿费、市内交通费、餐饮补贴、其他费用(根据是否涉及差旅控制显隐)

**借款信息**：同出差申请中的借款信息

**功能说明**：
| 功能键 | 说明 |
|-------|------|
| 复制 | 复制培训人员及费用详情信息 |
| 添加 | 添加培训人员及费用详情 |
| 删除 | 删除培训人员信息及费用详情 |
| 导出模板 | 下载培训人员导入模板 |
| 导入数据 | 导入培训人员清单 |
| 上传附件 | 添加电子附件 |
| 保存 | 保存单据信息 |
| 提交送审 | 保存并提交审批 |

**页面规则**：
1. 生成分录：无借款无需生成，有借款需自动生成，提供预览修改
2. 提交时判定是否超年度预算
3. 若涉及出差，需遵守差旅标准，超标准需填写超标原因
4. **同步培训日期至HR系统**用于考勤工时，有更新需多次同步
5. 审批流程分支：项目/成本中心承担、国内(含三地)/国外、差旅标准内/外、计划内/外、课程内/外
6. 单据复制功能同差旅申请单

### 4.2 员工报销类

#### 4.2.1 员工费用报销

**业务说明**：适用于公司员工日常费用报销，在业务发生后根据实际发票金额填写报销单，可选择冲销借款或直接支付。可选的费用类型受表单类型控制，选择不同的费用类型系统匹配对应的费用详情表单。发票影像上传并验真后，发票系统将税务接口返回的发票信息更新到报销单。

**业务流程**：
| 序号 | 流程节点 | 流程说明 | 参与人 |
|-----|---------|---------|-------|
| 1 | 填制单据 | 录入相应字段 | 经办人 |
| 2 | 是否需要关联申请单 | 根据费用类型配置 | 系统 |
| 3 | 关联部门或项目 | 选择成本分摊方式 | 经办人 |
| 4 | 选择申请单号/项目 | 关联已审批完成的申请单或项目 | 经办人 |
| 5 | 预算控制流程 | 预算扣减检查 | 系统 |
| 6 | 添加结算信息 | 录入结算信息、冲销借款 | 经办人 |
| 7 | 提交单据 | 系统校验 | 经办人 |
| 8 | 业务审批 | 各级领导审批 | 业务领导 |
| 9 | 财务处理流程 | 支付、记账 | 财务人员 |

**系统界面**：费用报销单

**字段详情**：

#### 4.3.4 机票结算申请

### 4.5 员工还款申请

**业务说明**：适用于员工之前有借款在报销时未冲销完毕，需退还剩余借款的业务。可一个还款单同时冲销多笔借款单，可替他人填制还款单。

- 一个还款单可同时冲销多笔借款单
- 可替他人填制还款单
- 支持还款人与制单人不一致

**业务流程**：

| 序号 | 流程节点 | 流程说明 | 参与人 |

| 3 | 业务审批 | 各级业务领导进行工作流审批，审批不通过的单据将会打回经办人处修改，修改完毕后再进行提交 | 业务领导 |
