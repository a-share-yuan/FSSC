# 12-出纳批量付款设计说明书（P10）

> 阶段：P10 出纳批量付款 
> 覆盖：PAY 付款单 → 付款记录 → 付款批次 → 确认 → 执行付款（模拟银行）→ 单据回写
> 位置：`com.fssc.sharing`（PayBatchService）+ `com.fssc.expense`（ExpBillPayment）

---

## 1. 本阶段交付

| 表 | 说明 |
|---|---|
| exp_bill_payment | 单据付款记录：收款人/账户/金额，WAITING → PAID/FAILED，回写批次号/流水号 |
| op_pay_batch | 付款批次：出账账户/合计/笔数，DRAFT → CONFIRMED → PAID |
| op_pay_batch_detail | 批次明细：收款人/账户/金额/用途，WAITING → SUCCESS/FAILED + 银行流水号 |

### 链路

```
PAY 付款单（exp_bill，提交审批）
  → APPROVED → 生成付款记录（WAITING）
  → 出纳建批（DRAFT）→ 加明细（自动带收款信息）→ 确认（CONFIRMED）
  → 执行付款（模拟银行：明细 SUCCESS + bankSerial → 批次 PAID + bankResp）
  → 回写：付款记录（PAID/批次号/流水号）+ 单据（paid_amount += 金额）
```

接口 `/api/tenant/pay/**`：payment/create、payment/list、batch/create、batch/{id}/detail、
batch/{id}/confirm、batch/{id}/execute、batch/page、batch/{id}/details。权限码 `pay:*`。

## 3. 设计要点

1. **付款记录与单据解耦**：付款记录（exp_bill_payment）独立于单据主表，支持一单多次/分批付款；
   批次执行后按明细回写对应单据 paid_amount。
2. **批次汇总实时维护**：加明细即同步 total_amount / detail_count；执行时校验必须 CONFIRMED。
3. **银行对接预留**：execute 目前为模拟（SUCCESS + bankSerial）；接入银企直联时替换 execute 的
   银行调用段，回写逻辑复用。
