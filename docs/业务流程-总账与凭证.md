# 业务流程：总账与凭证

总账域是财务数据的终点：所有业务动作最终都落成 `gl_book_voucher` 的分录，
月结是"这个月能不能关"的总闸门。

## 1. 流程总览

```
业务单据(报销/应付/应收/资金/资产) ──► [凭证生成] ──► [凭证复核] ──► [记账]
                                                          ↓
[期末处理: 结转/汇兑/税费] ──► [月结检查] ──► [关账] ──► [报表]
```

## 2. 环节详解

### 2.1 账簿体系（gl 域）
- 多账簿（`gl_accounting_book`）：按公司/核算维度分设，凭证按规则分流；
- 科目体系（`md_subject`）：一级科目 + 明细科目两级，支持现金流转自定义项映射。

### 2.2 凭证生成
- **自动**：业务单据按凭证模板（`op_voucher_template`）生成，借贷必须平衡；
- **手工**：`GL_MANUAL_VOUCHER` 流程驱动手工凭证录入与审批；
- **合并**：`GL_MERGE` 把同类自动凭证合并（如费用报销按科目汇总）；
- 生成失败必有原因（科目缺失/借贷不平/维度缺值），不允许"静默不生成"。

### 2.3 凭证复核与记账
- 复核人 ≠ 制单人（SoD 检查）；
- 记账后修改只能冲销（红字），不留"改历史"的口子。

### 2.4 期末处理
- 汇兑损益（`gl_fx_revaluation`，多币种账簿）；
- 税费计提（`gl_tax_provision`/`tax_declaration`）；
- 薪酬结转（`gl_salary_run`）；
- 合并报表底稿（`gl_consolidate`，多公司口径）。

### 2.5 月结（gl_month_close / gl_close_check_item）
- 检查清单逐项过：凭证平衡、分录合计、模块间一致性（应收/应付/资金/影像）、
  银行对账未平项、折旧/摊销完整性；
- **全部通过才允许关账**；任一项不过，关账按钮就是禁的，并列出差在哪。

## 3. 关键表

| 表 | 作用 |
|---|---|
| `gl_book_voucher` / `_line` | 凭证头/分录 |
| `gl_accounting_book` | 账簿 |
| `gl_book_balance` / `gl_book_subject_map` | 科目余额/映射 |
| `gl_month_close` / `gl_close_check_item` | 月结与检查项 |
| `md_subject` | 科目主数据 |

## 4. 演示路径

1. 走一张报销单到付款完成（见费用报销篇）；
2. 总账 → 凭证查询 → 按单据号找到自动凭证；
3. 凭证复核 → 记账；
4. 期末处理 → 月结 → 看检查清单逐项变绿。

## 5. 排障速查

| 现象 | 先查 |
|---|---|
| 单据走完了没凭证 | 凭证模板映射 / 科目缺失 / 平衡校验失败原因 |
| 月结关不了 | `gl_close_check_item` 未过项逐条看 |
| 汇兑损益不对 | 汇率表（`md_exchange_rate`）期间与来源 |
| 合并报表差 | 内部交易抵消（`gl_inter_offset`）配置 |
