## 四、已知边界与遗留

1. **admin 数据范围**：admin 无角色 → dataScope 默认 SELF → 方案/明细页只显示本公司（公司1）数据。其他公司方案已入库，各公司用户按其角色数据范围可见本公司方案。如需 admin 看全租户，需给 admin 挂一个 data_scope=TENANT 的角色（属权限变更，待确认）。
2. **预算执行页 itemName 显示**：后端 `BudgetService.executionSummary` 拼的是"预算项#id dimKey"，可读性差。改进需改 Java（`mvn compile` 后须重启 8089 才生效），待重启窗口一并处理。
3. **费用项映射**：`md_item_budget_map`（211 条）仍指向存量 4 条综合明细（19-22），真实报销/付款单的预算校验链路不受本次数据影响。
