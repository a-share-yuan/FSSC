# 业务流程：费用报销全流程

费用报销是 FSSC 最完整的业务链：一张单子串起预算、合规、审批、影像、发票、
付款、凭证、归档八个环节。读懂这一篇，其它域都是变体。

## 1. 流程总览

```
[新建申请] → [提单] → [预算校验] → [合规预检] → [多级审批] → [共享中心作业]
                                                              ↓
[付款] ← [出纳] ← [付款批次] ← [结算] ← [发票匹配] ← [财务审核] ←┘
   ↓
[自动凭证] → [月结] → [归档]
```

## 2. 环节详解

### 2.1 事前申请（exp_bill 前置）
- 差旅/大额支出先提申请单，报销时关联申请，**超申请金额自动走长审批链**；
- 申请有余量时按次核销。

### 2.2 提单（exp_bill / exp_bill_line）
- 表头：申请人/公司/部门/事由/币种；明细行：费用项（`md_expense_item`）、
  金额、票据张数、关联发票（`inv_invoice`）；
- 票据影像在提单时或作业时挂接（`exp_bill_receipt` → 影像库 `img_file`）。

### 2.3 预算控制（budget 域）
- 占用：`bg_occupy` 按方案（`bg_scheme`）扣减可用额；
- 超预算：拦截或走特批（按 `bg_scheme` 的管控级别）。

### 2.4 合规预检（compliance 域）
- 费用政策（职级标准/城市标准/费用项标准）逐行比对；
- 结果落 `precheck_result`：超标行高亮，**超标不是不能报，是必须给出理由并走对应审批**。

### 2.5 多级审批（workflow 域）
- 流程：`CLAIM` 模型（含差旅变体 `CLAIM_TRAVEL`）；
- 审批动作：通过/驳回（自由驳回到任意级次）/转办/加签/传阅；
- 超时自动升级：默认阶梯 提醒 → 升级 → （白名单内）自动通过。

### 2.6 共享中心作业（sharing 域）
- 派工规则（`op_dispatch_rule`）按公司/单据类型分派作业员；
- 作业员：初审（票据真伪/完整性）→ 装订 → 质检（`op_quality` 抽检）；
- SLA 计时（`op_sla_config`），超时升级并记 `op_sla_breach`。

### 2.7 财务审核与结算
- 齐套闸口：发票/合同/验收等必挂附件齐了才放行（`bill.completeness.gate`）；
- 生成结算单，进入付款排程。

### 2.8 付款（资金域）
- 出纳按付款计划（`pay_plan`）组批（`op_pay_batch`/`op_pay_batch_detail`）；
- 收款方账户来自 `md_payee`/`md_bank_account`（脱敏演示数据为虚构号）；
- 批次审批 → 银企通道执行（默认 mock）→ 回单登记（`exp_bill_payment`）。

### 2.9 凭证（总账域）
- 按凭证模板（`op_voucher_template`）自动生成 `gl_book_voucher`（借贷平衡校验）；
- 多账簿（`gl_accounting_book`）按公司/维度分流。

### 2.10 归档
- 影像档案化（`archive_*`），借阅/销毁有审批；
- 热数据超期移冷表（`exp_bill_cold`，逐列同序）。

## 3. 关键状态机

```
草稿 → 已提交 → 审批中 → 审批通过 → 作业中 → 待付款 → 已付款 → 已凭证 → 已归档
                    ↘ 驳回(回到草稿或指定节点)    ↘ 终止/作废
```

状态展示取 `bill_status_display` 字典，不在各页写死。

## 4. 演示操作路径

1. 用 `admin` 账号登录（租户 `DEMO1`；演示口令只在 `readme.txt` 第四节"验证安装"给一次，别处不重复）；
2. 我的工作台 → 费用报销 → 新建：选费用项、填金额、挂一张演示发票；
3. 提交 → 待办中心切审批人账号审批通过；
4. 共享作业控制台看派工结果；
5. 资金管理 → 付款批次 → 执行；
6. 总账 → 凭证查询 → 看到该单凭证；
7. 单据详情 → 流程轨迹 → 全链路联查（票据→付款→凭证）。

## 5. 排障速查

| 现象 | 先查 |
|---|---|
| 提交即被拦 | `precheck_result` 超标项 / 预算占用 / 齐套闸口 |
| 审批人不对 | wf_node_config 的 node_key 是否孤儿 |
| 看不到待办 | 连办拦截 / 数据范围 / 节点没配人 |
| 付款选不到账户 | 账户主数据页大小限制（已知 D-BIZ-04，用手册绕行） |
| 凭证不平 | 凭证模板映射 / 科目存在性（`md_subject`） |
