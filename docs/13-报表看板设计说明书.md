# 13-报表看板设计说明书（P11）

> 阶段：P11 报表看板 
> 覆盖：报销统计、月度趋势、预算执行率、付款进度（租户内聚合）
> 位置：`com.fssc.report`

---

## 1. 本阶段交付

| 接口 | 说明 |
|---|---|
| `/api/tenant/dashboard/expense/stats` | 报销按单据类型+状态分组（张数/金额） |
| `/api/tenant/dashboard/expense/trend` | 月度趋势（会计期间分组，近 N 月，张数/金额） |
| `/api/tenant/dashboard/budget/execution` | 预算执行率（按费用项：预算/调整/已用 + 执行率 used/(total+adjust)） |
| `/api/tenant/dashboard/pay/progress` | 付款进度（批次/付款记录：待付笔数金额、已付笔数金额） |

权限码 `dashboard:view`；全部走 **MP 聚合 SQL（selectMaps + groupBy）**，
租户拦截器自动注入 tenant_id —— 租户内聚合，天然隔离，无跨租户统计。

## 3. 本轮小修

- **单据会计期间未填**：saveDraft 按 apply_date 自动回填 period_year/period_month
  （看板月度趋势依赖）；存量单据 SQL 回填。
- **MP 聚合泛型**：selectMaps 需具体实体类型的 QueryWrapper（`QueryWrapper<?>` 编译不兼容）。
