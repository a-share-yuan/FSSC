## 2. 多租户适配

- 租户业务表（sys_* / wf_* / exp_* / inv_* / op_*）带 tenant_id，由 `TenantLineInnerInterceptor` 自动隔离，
  实体字段标 `@TableField(fill = INSERT)` 触发填充。
- 平台表（pf_*）无 tenant_id，**租户归属用 `ref_tenant_id`**（架构铁律），不参与租户改写。
- 跨租户统计（pf_tenant_stat 聚合）必须 `TenantContext.runIgnoreTenant()` 且只允许聚合，禁止查明细。

## 3. 实体基类选型（重要）

| 基类 | 审计类型 | 适用 |
|---|---|---|
| `TenantAuditBase` | tenantId + createBy/updateBy **Long** | md_*、sys_* 增强表（DDL create_by 是 bigint） |
| `PlatformBaseEntity` | 无 tenantId，createBy/updateBy **Long** | pf_*（有 del_flag） |
| 独立实体 | 按真实列逐一声明 | 审计列不齐（无 create_by/update_by 或 del_flag）的表 |

**P17 重大修复**：`TenantAuditBase` / `PlatformBaseEntity` 的 createBy/updateBy 补上了
`@TableField(fill = INSERT / INSERT_UPDATE)`。原因：MyBatis-Plus 仅在字段带 fill 注解时
才将该列纳入 INSERT/UPDATE 并交给 MetaObjectHandler 填充 —— 此前 create_by 一直为 NULL。
BaseEntity（String 审计）未加 fill：sys_* 表 create_by 是 bigint，若填 String 用户名会触发
MySQL 1366 错误，属遗留隐患，后续统一迁移 Long 审计。

## 4. 各批次要点

### 4.1 系统增强
- **文件存储**（sys_file + sys_file_token）：
  - 路径 `{root}/{tenantId}/{yyyyMM}/{bizType}/{uuid}.{ext}` 物理隔离；MD5 租户内秒传去重。
  - 下载两步走：`POST /file/{id}/token` 换一次性令牌（5 分钟）→ `GET /file/download?token=xx`
    （无 Authorization 头，白名单放行，token 即身份；校验与"用后即焚"UPDATE 均在 runIgnoreTenant 内）。
- **编号规则**（sys_number_rule + sys_number_seq）：
  - 取号并发安全：`UPDATE sys_number_seq SET current_val = current_val + step`（行锁）；
    0 行则 INSERT 初始行（唯一键 uk_tenant_rule_cycle 防并发，冲突重试一次）。
  - 编号 = prefix + 日期（按 reset_cycle）+ 流水补零。业务侧禁止手写前缀拼号。

### 4.2 流程增强（门面双写打通）
- **WfEngineFacade 双写**（业务禁止直调 Flowable API 的红线不变）：
  - `start()` → 落 wf_instance（RUNNING）
  - `complete()` → 落 wf_task_history（APPROVE/REJECT，操作人留痕）
  - PROCESS_COMPLETED 事件 → 追加收尾历史（APPROVED/REJECTED）+ wf_instance 状态回写
  - 注意：流程变量在流程结束后被引擎清理，写历史时 bizType/bizId 改从 wf_instance 视图取。
- **流程绑定路由**（wf_process_config）：按 biz_type + priority 从大到小取第一条
  公司/部门/金额区间命中的规则，返回 modelKey，禁止硬编码 processKey。
- **查询视图**（wf_instance / wf_task / wf_task_history / wf_cc）：待办/历史/抄送只查业务视图表，
  不与 ACT_* 联查（引擎表是隔离盲区且历史会被清理）。

### 4.3 报销/发票/运营增强
- 分摊（exp_bill_share）：整单覆盖保存 replaceForBill；金额 >0 校验。
- 轨迹（exp_bill_trace）、验真日志（inv_verify_log）：**审计表，Mapper 不提供 delete，只增不改**。
- 发票明细行（inv_invoice_line）：费用行与发票行勾稽。
- 质检（op_quality）、档案（op_archive）：RANDOM/FULL 抽检；档案编号唯一、可销毁（DESTROYED）。
- 银行流水（op_bank_statement）：uk_tenant_serial 防重，重复导入幂等忽略；对账标记 RECONED。

### 4.4 平台 SaaS
- 订单（pf_order）：confirmPaid 自动回写服务周期（start/end ± duration）。
- 账单（pf_bill）：receivePayment 累计 paid_amount，达应收自动 PAID。
- 配置（pf_config）与租户 sys_config **物理分表**（防租户改平台参数）。
- 消息模板（pf_notice_template）：渠道 INNER/SMS/EMAIL/WECOM/DINGTALK，占位符 ${xxx}。
- 用量统计（pf_tenant_stat）：日快照 upsert 幂等；跨租户聚合仅 sum/count。
