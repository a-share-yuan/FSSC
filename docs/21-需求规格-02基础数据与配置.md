# 基础数据与配置

### 2.1 基础数据通用说明

#### 状态
- 所有基础档案统一使用"启用/停用"状态控制
- 已停用的数据在引用时不可见

#### 列表查询模式
- 列表页支持：关键字查询、高级筛选、分页展示
- 支持导出Excel

### 2.6 流程管理

**业务说明**：（来源于Word详细设计方案，此处保留原文概述）

**字段说明**：

| 字段名称 | 录入控制 | 录入方式 | 备注 |
| --- | --- | --- | --- |
| 编号 | 必填 | 手工录入 |  |
| 名称 | 必填 | 手工录入 |  |
| 流程说明 | 选填 | 手工录入 |  |
| 单据类型 | 必填 | 选择框-单据详情 |  |
| 优先级 | 必填 | 手工录入 | 数值越低的优先级越高，系统优先匹配优先级高的流程，若流程的启动条件不满足，系统再匹配优先级低的流程 |
| 启用状态 | 自动生成 | 不可编辑 | 启用状态有：已禁用、已启用 |
| 发布状态 | 自动生成 | 不可编辑 | 发布状态有：未发布、已发布、可发布新版 |

**功能说明**：

| 序号 | 功能键 | 功能键说明 |
| --- | --- | --- |
| 1 | 新增 | 新增一条审批流程 |
| 2 | 查看 | 查看流程信息并可进行编辑 |
| 3 | 复制 | 以当前流程为模板复制一条新的流程 |
| 4 | 配置流程 | 打开流程配置界面进行流程配置 |
| 5 | 启用流程 | 当流程的状态为禁用时，可以对该流程进行启用 |
| 6 | 禁用流程 | 当流程的状态为启用时，可以对该流程进行禁用 |

**页面规则**：
- 发起入口（员工报销/对公支付页面）从启用类型列表动态渲染，管理员维护后即时生效，无需发版
