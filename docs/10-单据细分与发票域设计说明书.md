# 10-单据细分与发票域设计说明书（P8）

> 阶段：P8 单据细分 + 发票 + 凭证增强 
> 覆盖：差旅行、借款冲抵、单据关联、发票录入（价税分离）、凭证生成回写与记账
> 位置：`com.fssc.expense`（细分）+ `com.fssc.invoice` + `com.fssc.sharing`（凭证增强）

---

## 1. 本阶段交付

### 1.1 单据细分 `com.fssc.expense`

| 表 | 说明 |
|---|---|
| exp_travel | 差旅行：行程/交通（FLIGHT/TRAIN…）/住宿/补贴，合计与超标准标记 |
| exp_loan_offset | 借款冲抵：报销单冲抵借款单，联动 offset_amount/payable_amount |
| exp_bill_relation | 单据关联：事前申请↔报销、借款↔报销（APPLY_CLAIM/LOAN_CLAIM） |

接口 `/api/tenant/expense/detail/**`：travels 保存/查询、loan-offset 添加/查询、relation 创建/查询。

**借款冲抵联动**：`payable = max(申请/核定金额 - 累计冲抵, 0)`，冲抵后应付实时反映。

### 1.2 发票域 `com.fssc.invoice`

| 表 | 说明 |
|---|---|
| inv_invoice | 发票：**价税分离（amount = net + tax 校验）**，唯一键（租户+票号+代码）防重 |
| inv_bill_invoice | 单据-发票关联（bill/line 粒度） |

接口 `/api/tenant/invoice/**`：create（价税校验）、bind（关联单据）、page、bill-invoices。

### 1.3 凭证增强 `com.fssc.sharing`

- 生成凭证后**回写单据 voucher_no / voucher_date**；
- `POSTED` 记账：DRAFT → POSTED（记账人/时间）。

## 3. 本轮抓到的坑

1. **审计列不齐的表不能继承 TenantAuditBase**：exp_travel（无 create_by/update_by）、
   exp_loan_offset 与 inv_bill_invoice（有 create_by 但无 update_by/update_time）→
   select 时报 `Unknown column 'update_by'`。→ 按真实列声明独立实体。
2. **发票唯一键防重**：inv_invoice 有 `uk_tenant_inv(tenant_id, invoice_no, invoice_code)`，
   重复录入报 DuplicateKeyException（正确行为，验证脚本需用动态票号）。
3. **saveDraft 不计算合计**：草稿 total_amount 保持入参值；借款冲抵等联动计算依赖
   total/approved 金额，草稿期应显式带入或由行合计兜底（此处演示显式传入）。
