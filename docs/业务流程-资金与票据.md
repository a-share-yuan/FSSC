# 业务流程：资金与票据

资金域管"钱怎么计划、怎么出去、怎么对平"，票据域管"票怎么开、怎么收、怎么贴现"。
银企直连与 OCR 一样走 SPI，默认 mock 离线演示。

## 1. 资金流程总览

```
[资金计划 pay_plan] → [头寸视图] → [付款排程]
                                        ↓
[出纳组批 op_pay_batch] → [TR_PAY 审批] → [银企执行(SPI)]
                                        ↓
[回单/银行流水] ← [bank_balance] ←──────┘
       ↓
[银行对账 bank_reconcile] ──未平──► [差异处理] ──平──► [对账完成]
```

## 2. 环节详解

### 2.1 资金计划（payplan 域）
- 按期间/公司/收付类型编制计划（`pay_plan`）；
- 计划 vs 实际偏差在看板呈现，超计划付款需特批。

### 2.2 头寸与排程
- 账户余额（`bank_balance`）汇总各银行账户可用头寸；
- 排程按紧急度/账期/批次规则自动建议付款日。

### 2.3 出纳组批与执行
- 组批（`op_pay_batch`）：同银行/同币种/同时限的单据合成一批，提高执行效率；
- 批次审批走 `TR_PAY` 流程（确认→执行两档，齐套闸口把关）；
- 银企执行：`FSSC_BANK_GATEWAY=mock`（DefaultBankGateway 离线）或真实实现
  （凭据环境变量，禁入库）。

### 2.4 银行对账（bank 域）
- 银行流水导入（`op_bank_statement`）后与系统单自动匹配（金额+单号+账号）；
- 未平项逐笔列出，支持手工勾对（`bank_reconcile_item`）；
- **银企未平不允许月结**（总账月结检查项之一）。

### 2.5 票据（treasury 域）
- 应收票据（`tr_credit_bill`）：登记→持有→贴现/背书/到期收款；
- 应付票据：开票→承兑→到期付款；
- 票据状态变化全程留痕，参与资金头寸计算。

## 3. 关键表

| 表 | 作用 |
|---|---|
| `pay_plan` | 资金计划 |
| `op_pay_batch(_detail)` | 付款批次 |
| `tr_fund_plan`/`tr_transfer` | 资金调拨 |
| `bank_balance`/`bank_reconcile` | 余额/对账 |
| `md_bank`/`md_bank_account` | 银行/账户主数据 |
| `tr_credit_bill` | 票据 |

## 4. 安全口径

- 银企直联是资金出口：通道实现必须可替换（SPI），真实凭据只进环境变量；
- 批次执行双人原则：制单 ≠ 审批 ≠ 执行（SoD）；
- 所有资金动作（组批/审批/执行/回单）落 `op_plan_paid_log`/`audit_trail`。

## 5. 演示路径

付款批次生成（报销/应付单进来）→ 组批 → TR_PAY 审批 → mock 执行成功 →
银行流水导入 → 对账 → 查看头寸看板。
