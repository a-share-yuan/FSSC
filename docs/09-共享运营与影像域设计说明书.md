# 09-共享运营与影像域设计说明书（P7）

> 阶段：P7 共享运营 + 影像 + 凭证 
> 覆盖：派工单（审批通过自动入池/认领/完成）、影像批次（页面/OCR 状态/单据影像状态回写）、记账凭证（借贷分录）
> 位置：`com.fssc.sharing` + `com.fssc.image`

---

## 1. 本阶段交付

### 1.1 共享运营 `com.fssc.sharing`

| 表 | 说明 |
|---|---|
| op_audit_task | 派工单：bill 维度，task_type（AUDIT/POST/PAY），pool_status（WAITING/RECEIVED/FINISHED），SLA |
| op_voucher | 记账凭证：借贷合计、平衡标记、POSTED 记账状态 |
| op_voucher_line | 凭证分录：科目/方向/金额/辅助维度（dept/project/supplier） |

链路：**审批通过 → 自动生成派工单入池（WAITING）→ 认领（RECEIVED，归属当前用户）→ 完成（FINISHED）→ 凭证生成**。

接口 `/api/tenant/sharing/**`：task/pool、task/mine、task/{id}/receive、task/{id}/finish、
voucher/generate/{billId}、voucher/page、voucher/{id}/lines。权限码 `sharing:*`。

### 1.2 影像域 `com.fssc.image`

| 表 | 说明 |
|---|---|
| img_batch | 影像批次：UPLOADED/CHECKED，业务关联（biz_type/biz_id） |
| img_file | 页面级：OCR 状态（NONE/PENDING/SUCCESS/FAILED）、verify 状态、识别文本 |

上传批次 → 回写 `exp_bill.image_status = COMPLETE`（NONE→COMPLETE）。OCR 能力留 P8。

### 1.3 凭证生成规则（P7 简化演示）

```
借：费用行金额（科目 = 行科目 → 费用项绑定科目 → 6602 管理费用兜底）
贷：合计（科目 = 2241 其他应付款，租户未建科目时兜底 6602）
借贷平衡 → is_balanced=1
```

## 3. 本轮抓到的坑

1. **op_voucher_line.subject_id 是 NOT NULL**：贷方行只设了 subjectCode/Name 忘设 subjectId →
   `Column 'subject_id' cannot be null`。→ 所有分录行必须解析出真实科目 id
   （借方：行→费用项→6602 兜底；贷方：2241→借方科目兜底）。
2. **科目 id 漂移残留**：seed-p4 重跑后 md_subject 6602 的 id 从 1 变 5，md_expense_item.subject_id
   仍引用旧 id → 解析时必须 `selectById` 校验存在性，失效则回退 6602。
