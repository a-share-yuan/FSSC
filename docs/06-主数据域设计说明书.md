# 06-主数据域设计说明书（P4）

> 阶段：P4 主数据域 
> 覆盖：币种/税率/会计科目/费用项/供应商/收款人/公司银行账户/项目（8 张核心主数据）
> 位置：`com.fssc.masterdata`

## 1. 本阶段交付

| 主数据 | 表 | 说明 | 归属 |
|---|---|---|---|
| 供应商 | md_supplier | 报销收票方，支持黑名单 | 租户级共享 |
| 收款人 | md_payee | 付款对象（员工/供应商/其他），默认收款账户 | 租户级共享 |
| 公司银行账户 | md_bank_account | 出账账户，含余额 | 按公司 company_id |
| 费用项 | md_expense_item | 树形，绑定科目/税率/发票/附件/预算/标准控制 | 租户级共享 |
| 会计科目 | md_subject | 树形，company_id 为空=共享科目 | 租户级共享 |
| 项目 | md_project | 成本归集单元，总预算/已用 | 按公司 company_id |
| 币种 | md_currency | 本位币标记 is_base | 租户级共享 |
| 税率 | md_tax_rate | 发票/费用取税 | 租户级共享 |

接口统一 `/api/tenant/masterdata/{域}/**`：page（关键词搜索）/ create / update / {id}/enable；
树形域（expense-item、subject）另提供 `tree`。
权限码 `md:{域}:list|create|update`；写操作全部落 `sys_oper_log` 审计。

## 2. 关键设计

- **实体基类 TenantAuditBase**：md_* 表 `create_by/update_by` 为 **bigint**（记录用户ID），
  与 sys_* 表（varchar 用户名）不同，不能复用 BaseEntity。
  MetaObjectHandler 已按字段类型自适应填充（Long→userId / String→username）。
- **数据范围**：供应商/收款人/费用项/科目/币种/税率为租户级共享（整租户可见）；
  银行账户/项目按公司归属（company_id），报销取数时校验。
- **费用项即报销骨架**：树形分类（差旅费→市内交通）、绑定默认科目、默认税率、
  need_invoice/need_attach/budget_control/std_control（报销单校验与预算控制的依据）。
- **科目树**：科目编码（如 6602→660203）天然有序，树接口按 subjectCode 排序返回，前端按 parentId 组树。

## 4. 本轮要点

1. 主数据表 `create_by` 为 bigint → 新增 `TenantAuditBase`（带 tenantId + Long 审计），
   与 BaseEntity（String 审计）并存，MetaObjectHandler 类型自适应已支持。
2. 生成 8 组 Service/Controller 时按域定制搜索字段与树形接口（Subject 无 ancestors 列，
   树排序改用 subjectCode）。
3. 租户隔离验证要构造"有权限但跨租户"的账号（carol 授 md:supplier:list），
   否则会被权限防线先拦（4030），无法证明数据隔离。
