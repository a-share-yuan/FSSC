# FSSC 配套文档索引

本目录是 FSSC 集团财务共享服务平台的配套文档，与 `readme.txt`（快速安装）互补：
readme.txt 解决"跑起来"，本目录解决"看懂它、用好它、改得动"。

## 阅读路线

| 角色 | 推荐阅读顺序 |
|---|---|
| 第一次接触（任何人） | 系统介绍 → 系统特点 → 快速上手 |
| 业务/实施顾问 | 系统介绍 → 业务流程系列（8 篇） |
| 后端开发 | 代码阅读指南 → 模块地图 → 数据模型 → 权限与多租户 → 流程引擎技术说明 |
| 前端开发 | 模块地图 → 权限与多租户 → 相关业务流程 |
| 运维/交付 | 快速上手 → 部署手册 → 部署运维 |

### 逐步操作手册（3 本）
不讲概念，只讲"谁、登哪个账号、点哪里、应该看到什么"——每步都带预期结果，照做即可跑通一条完整业务链路。

- [费用报账全流程（新手逐步版）](真实场景测试/01-人工测试操作手册-费用报账全流程-新手版.docx)：
  出差申请 → 部门经理驳回 → 编辑重提 → 多级审批 → 借款 → 报销冲抵 → 付款 → 凭证 → 归档，逐幕标注账号与预期状态
- [其它业务流程与功能（新手版）](真实场景测试/02-人工测试操作手册-其它业务流程与功能-新手版.docx)：
  67 个业务菜单拆成 11 章，标明"真跑还是只读观察"
- [系统管理员与流程配置（新手版）](真实场景测试/03-人工测试操作手册-系统管理员与流程配置-新手版.docx)：
  主数据 / 权限 / 编号规则，含受控流程模型 `GTEST_ADMIN_FLOW` 的完整建-校验-发布走法

> 演示租户 `DEMO1`（爱共享公司），口令统一 `123456`，工号即登录账号。三本手册 §1.2 各自列出本册要用的账号表
> （例：`100001/丁宇轩` 提单、`100075/高洋` 直属上级、`100005/叶思琪` 部门经理、`100002/赵勇` 共享会计、`100003/雷子涵` 出纳）。
> **同一个人不能既提单又审批**（引擎有防自审判定），跑完整链路至少要准备提单人 + 部门审批人 + 共享会计 + 出纳四类身份。

## 文档口径说明

- 文中数字来自源码扫描（`_tools/inventory.mjs` → `_tools/emit_facts.mjs`）或库结构，
  会标注获取方式；未标注的为结构性描述。数字会随版本漂移，**引用前重跑一次，别抄册子里的**。
- 演示环境统一口径：租户 `DEMO1`（爱共享公司），口令统一 `123456`。**账号与演示路径以
  [`真实场景测试/`](真实场景测试/) 三本手册为准**（每本 §1.2 有本册账号表，正文逐步点名"此步用哪个账号"）；
  `readme.txt` 第四节只给 admin 与 100001 两枚入门账号。**投产前必须重置全部口令并删除演示账号**。
- 文档随版本演进，如与代码不一致，以代码与 `db/README.md` 为准，
  并欢迎提 issue 指正。
