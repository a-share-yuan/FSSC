# FSSC 配套文档索引

本目录是 FSSC 集团财务共享服务平台的配套文档，与 `readme.txt`（快速安装）互补：
readme.txt 解决"跑起来"，本目录解决"看懂它、用好它、改得动"。

## 阅读路线

| 角色 | 推荐阅读顺序 |
|---|---|
| 第一次接触（任何人） | 系统介绍 → 系统特点 → 快速上手 |
| 业务/实施顾问 | 系统介绍 → 业务流程系列（8 篇） |
| 后端开发 | 代码阅读指南 → 模块地图 → 数据模型 → 权限与多租户 → 流程引擎技术说明 |
| 前端开发 | 模块地图 → 权限与多租户 → 相关业务流程 |
| 运维/交付 | 快速上手 → 部署手册 → 部署运维 → 开源发布前置检查清单 |

## 文档口径说明

- 文中所有"实测数字"来自源码扫描（`_tools/emit_facts.mjs`）或数据库实测，
  会标注获取方式；未标注的为结构性描述。数字会随版本漂移，**引用前重跑一次，别抄册子里的**。
- 演示环境统一口径：租户 `DEMO1`（爱共享公司）。**演示账号与口令只在 `readme.txt` 第四节"验证安装"给一处**，本目录不重复，改一处即可；投产前必须重置。
- 文档随版本演进，如与代码不一致，以代码与 `db/README.md` 的实测口径为准，
  并欢迎提 issue 指正。
