# 业务流程：共享作业运营

共享中心把分散的财务作业集中处理，"运营"就是把这条生产线管起来：
活怎么分、人怎么排、时效怎么保、质量怎么抽。`op_*` 系列 28 张表是这套机制的家。

## 1. 运营总览

```
[单据池] → [派工规则 op_dispatch_rule] → [作业员队列 op_job]
                ↓                              ↓
        [排班 op_calendar]              [SLA 计时 op_sla_config]
                ↓                              ↓
        [作业执行: 审核/装订/复核] ← [超时升级 op_sla_breach]
                ↓
        [质量抽检 op_quality] → [整改 op_review_log] → [稳定性看板 op_stability_log]
```

## 2. 环节详解

### 2.1 派工（sharing 域）
- 规则（`op_dispatch_rule`）：按公司/单据类型/金额段/作业类型分派到组或个人；
- 派工日志（`op_dispatch_log`）全留痕，支持改派（转办同类）；
- **业务动作归属闸**：申请人不能看到自己单据的审批按钮，审批人不能审自己的单
  （同人连办拦截）——按钮显示错是高频缺陷，改 UI 前先查归属判定。

### 2.2 排班（op_calendar / op_group）
- 共享中心按日历排班，作业量按日预测；
- 作业员心跳（`op_job_heartbeat`）感知在线状态，掉线自动重派。

### 2.3 SLA 与升级
- SLA 配置（`op_sla_config`）按作业类型设目标时长；
- 超时记违约（`op_sla_breach`）并按阶梯升级：提醒 → 换人 → 上报。

### 2.4 质量与复核
- 抽检规则（`op_review_rule`）：按比例/按风险（金额/供应商/费用项）抽检；
- 复核记录（`op_review_log`）不合格进整改，整改闭环才销项。

### 2.5 看板与稳定性
- 作业量/时效/质量/稳定性四张看板（`op_stability_log`）；
- 稳定性指标：卡单率、异常率、重开率——共享中心的"生产线 OEE"。

## 3. 关键表

| 表 | 作用 |
|---|---|
| `op_dispatch_rule/log` | 派工规则与日志 |
| `op_job(_heartbeat)` | 作业与心跳 |
| `op_sla_config/breach` | SLA 与违约 |
| `op_review_rule/log` | 复核规则与记录 |
| `op_calendar`/`op_group` | 排班与作业组 |
| `op_quality` | 质量抽检 |

## 4. 运营例会数据哪来

- 昨日作业量/积压：`op_job` 按状态汇总；
- 超时 TOP：`op_sla_breach` 按作业类型；
- 质量趋势：`op_quality` 合格率按周；
- 卡单清单：`wf_task` 停留时长 + 节点配置孤儿排查。

## 5. 演示路径

管理员 → 共享运营 → 派工规则（默认已配）→ 提交几张报销单 →
控制台看到自动派工 → SLA 计时 → 抽检记录 → 看板。
