# 17-可视化图表看板设计说明书（P15）

> 阶段：P15 可视化图表看板 （ECharts）

---

## 1. 本阶段交付

| 图表 | 类型 | 数据源 |
|---|---|---|
| 报销统计（按类型/状态） | 环形饼图（占比 + 张数） | `/dashboard/expense/stats` |
| 付款进度 | 环形图（已付/待付笔数） | `/dashboard/pay/progress` |
| 月度趋势 | 柱状（单量）+ 折线（金额）双轴 | `/dashboard/expense/trend` |
| 预算执行率 | 横向条形（执行率%，>80% 红色预警） | `/dashboard/budget/execution` |

技术要点：
- `echarts` 全量引入（Dashboard chunk ~1MB，可按需引入优化）
- `Promise.all` 并行取数 → `nextTick` 后初始化图表（容器就绪）
- `window.resize` + `matchMedia` 监听 → `chart.resize()`（移动端/窗口缩放自适应）
- 组件卸载 `dispose` 图表防泄漏
- 数据加载失败静默降级（不阻塞页面）
