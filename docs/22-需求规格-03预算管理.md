### 3.10 关联单据的预算控制流程

**业务说明**：费用单据在提交时触发预算检查，预算是占用、释放、扣减的完整流程。

**业务流程**：
1. 单据提交 → 预算检查 → 预算充足则占用预算
2. 预算不足时：柔性控制（允许提交但预警）/ 刚性控制（不允许提交）
3. 单据关闭/作废 → 释放预算
4. 报销完成 → 实际扣减预算
