### 1.3 五条纪律（违反＝本次测试作废）

1.  **不许删任何数据**：不点【删除】【作废】【销毁】【清空】，不执行任何 删除、清空整表、删表。
2.  **admin 绝不提单、造单、审批、办理**：admin 只在系统管理域写入；在业务域只允许只读观察。本册 H10 用 admin 翻报表，也只读。
3.  **只按手册输值**：金额、日期、供应商、客户、账户都照表抄；不要临场改用别的单位或金额。
4.  **屏幕出现红色报错、白屏、数字对不上，立即停手**：截图、抄单号、记到记录表，不要靠反复核击“试过去”。
5.  **只用 FSSC**：不去 BCP 发起异议、不查 ERP、不做跨系统回写。BCP 页只验证“能打开”。

另外两条与审批有关的硬规则： - **不用转办、改派、挑唯一角色持有人制造自审节点**。自然不可达就记为「暂不适用」，把证据写进记录表。 - **不为了让流程通过去改引擎守卫、改系统参数、改节点配置**。本册所有链路都按 2026-10-22 现役配置设计。 - **审批入口有两个**：①「我的工作台›我的待办」行尾是**图标按钮**（悬停提示＝审批通过／退回驳回／全链路追溯），没有写着「通过」两个字的按钮；②「流程中心›审批工作台」（地址，需 wf:task:list，本册 22 个业务账号都具备）行内才有文字按钮【去处理／通过／驳回／核减／转办／加签／追溯】。**本册一律用②**。 注意：「去处理」会跳进单据自己的页面。若该账号没有那个页面的查看权限，**2026-10-22 修复后不再被弹回工作台**：系统只弹一句「当前账号不能直接进入该单据的业务页面，已打开全链路追溯」并打开追溯抽屉；办理仍用同行的图标按钮或审批工作台的文字【通过】。不要以为是单据丢了。

### 1.5.1 换人登录的读法（新手先看这一条，不要跳过它就会卡住不知道下一步该谁登）

1.  **「谁」列写的是账号/姓名 ⇒ 这一步就换那个人登录**：右上角头像 →【**退出登录**】（不要只刷新页面不会换身份）→ 登录页企业编码 **DEMO1** → 账号＝该行账号（或 admin）→ 口令 **123456** → 登录后先核对右上角姓名与手册一致再动手。**口令连错 3 次会锁号 ⇒ 不要试密码。**
2.  写着「**我的待办**」的行＝左侧菜单「**流程中心 › 审批工作台**」。**注意：界面上没有叫「我的待办」的菜单项**（「流程中心」下只有流程概览／我的单据／**审批工作台**／我的委托代理），待办都在审批工作台里；进去后**按业务单号搜**（合同名 DEMO…／付款计划号／应收单号／调拨单号／资产卡片号／预算方案号），不要拿流程实例号（那串 UUID）搜。
3.  写着「**我的待办／共享任务池**」的行＝该节配置为**抢单池**。**2026-10-27 全册复核：本册 5 条链的每一节都被 Dispatch=1 直接指派到名 ⇒ 行内只给【释放】不要给【领取】，直接点【通过】即可**（H2.5 汪佳怡／H4.4 雷子涵／H5.2 周磊三处实证；行内显示「姓名（账号）N 人可办」＝已到你名下、别人也能办）。只有当行内真的出现【领取】时才需要”先领取再办理”，找不到【领取】就以为页面坏了。
4.  **下一节那个人的待办里没有这张单＝正常**（上一节还没办结）。回上一节补做，不要反复刷新、不要改节点配置把人派给自己。
5.  若在同一张单上被提示「禁止同一人在同一审批流程中连续办理多个节点（连办/自审拦截）」＝**连办拦截**：本册纪律不转办、不改派 ⇒ 停手，把「哪一节、哪个账号、屏幕上显示的名字」记进记录表并喊系统管理员，不要改系统参数或改库绕过拦截。
6.  admin 只在本册 H10 报表章做**只读**翻页：不提单、不审批、不办理任何业务节点（1.3 节 纪律 2）。
7.  **「抓不到弹出提示」是数字方法问题，不是产品现象**：el-message 约 **3 秒自毁**，点完按钮隔一次工具往返再读就一定读空。本次在同一拍内读到的弹出提示有：「已发起【采购付款计划】审批」「已保存（收货超单会自动拦截）」「保存成功」「操作成功」「已提交审批…」「凭证 JZ2026102700024 已过账」「已下达」「已执行…」⇒ **对照标准仍以「弹窗关闭＋列表新行＋库表/流程实例落库」为主**（这条纪律不变），但正文里”抓不到提示”的字样一律按”当时读晚了”理解。
8.  **行内按钮集合随账号角色变**：同一张单，建单人侧与审核人侧看到的按钮不同——本次采购退货／销售退货 **待审核行在 100002 侧＝详情/审核/驳回/作废**，草稿行在建单人侧＝详情/编辑/提交/删除。**【作废】与【删除】本册一律不要点**（作废权限在共享主管，删除是破坏性动作）；按钮没渲染 ≠ 问题，渲染了 ≠ 可以让测试员点。

## 三之二、注意：填表“无反馈”的六类成因与自检法新手最常见的问题不是系统坏，而是“字段没真正填进去”。提交前按这六条自检：

| 现象 | 真实原因 | 自检法 |
|----|----|----|
| 点保存没反应，也没红字 | 必填项没填，红字提示在字段下方或页面顶部，被滚动条挡住 | 从页头往下逐项看红星；把窗口拉高再点一次 |
| 供应商/客户/科目明明输了字，保存却说“请选择” | 只输入了文字，没有点中下拉列表里的那一项 | 重新输入关键字，等列表出现，**用鼠标点中整行**，输入框变成“编码名称”才算选中 |
| 金额保存后变 0 或报格式错 | 输成了全角数字、带千分位、带“元”、或负数 | 只输半角数字和小数点；金额最多两位小数 |
| 日期报错/保存后变成今天 | 手打了 2026.10.22 或 2026/10/22 | 点日历图标选日期；期间字段只输 6 位 YYYYMM |
| 收货/退货保存被拦 | 没选上游采购订单；收货金额超过订单未收金额；退货表头金额≠明细合计 | 先选订单让供应商自动带出；核对“未收金额”；表头金额＝明细金额之和，误差不超过 0.01 |
| 按钮看不见，或点审批报“不能审批自己提交的单” | （这一格是数据库侧核对，语句收在附录 C；屏幕上看到的状态以正文为准） | 换手册指定的审批账号；不要转办、改派、换唯一持有人绕过 |

### 4.5 什么时候立即停手

- 页面白屏、控制台红色报错、列表一直转圈超过 1 分钟。

- 审批待办出现在**发起人自己**的待办里，且页面允许他审批（这违反 =1，是真问题）。

- 任何“删除成功、作废成功、销毁成功”的提示（本册不允许这些操作，出现即停）。
