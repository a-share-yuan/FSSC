# 共享运营

### 8.1 基础配置

#### 8.1.1 岗位设置
- 定义财务共享中心涉及的作业人员岗位
- 岗位需指定作业项（审核、记账、支付处理等）

#### 8.1.2 分组管理
- 按共享业务类型维护业务分组（费用组、资金组、应收组、应付组等）
- 可按照分子公司区域或行业划分
- 负责人管理工单任务，成员任务数上下限配置
- 任务提取方式：手动提取/系统提取

#### 8.1.3 工作日历
- 定义标准工作时间和例外工作日历
- 休息日/工作日定义
- 在岗时间定义

### 8.2 共享派单

#### 8.2.1 抢派单规则
- 定义工单任务分派到各小组任务池的规则条件
- 分派模式：系统分派/人工处理
- 规则条件：按共享作业项、公司、费用类型、币种组合

#### 8.2.2 任务池管理
- 查看所有工单任务的分配状态和处理情况
- 支持撤回、重新分配
- 任务状态：已分派、退单待分派、撤回待分派、手动分派、未分派到岗位、未分派业务组

#### 8.2.3 工单处理
- 共享作业人员处理分派的工单任务
- 支持凭证预览和修改分录信息
- 退单操作：退回至业务组任务池

## 8.6 档案归档闭环（已实现）

### 归档条件
- exp_bill 状态 APPROVED/PAID + 影像完整（image_status PARTIAL/COMPLETE）+ 未归档（archive_status != ARCHIVED）

### 归档执行（事务）
1. 收集单据关联文件（附件 exp_bill_attach.fileId + 影像 img_file.fileId）
2. FileService.moveZone(fileId, ARCHIVE)：物理迁移 business → archive + 更新 file_path/storage_zone（同区幂等）
3. 生成档案记录 op_archive（档案号 AR+时间戳、关联单号、保管年限 10 年、状态 ARCHIVED）
4. exp_bill 标记 archive_status=ARCHIVED + archive_time/archive_by

### 页面（共享运营 → 档案归档，独立页 ArchivePage.vue）
- Tab 待归档：复选 + 「归档所选」批量归档 + 查看影像
- Tab 已归档档案：档案列表 + 查看影像（归档区预览）

### 接口
- GET /sharing/enhance/archive/pending（待归档清单）
- POST /sharing/enhance/archive/do-archive（billIds[] 归档执行）

## 8.7 共享工单影像查看
- 工单处理页「查看影像」：billApi.detail(billId) → attaches fileId → FileViewer 预览（共享审核必看单据影像/发票）
