# 14-前端报销工作台设计说明书（P12）

> 阶段：P12 H5/PC 前端 （Web 工作台）
> 技术栈：Vue3 + Vite + Element Plus + Pinia + vue-router + axios
> 位置：`fssc-web/`（构建产物 dist/，预览 4173 端口，/api 代理到 18080）

---

## 1. 本阶段交付

| 页面 | 功能 |
|---|---|
| 登录 | 企业员工/平台管理员双通道，tenantCode 识别租户 |
| 主布局 | 侧边导航（静态：看板/报销/审批/付款）+ 退出登录 |
| 报销管理 | 填单（费用项/金额/预算项多行明细）+ 保存草稿 + 提交审批 + 我的单据（撤回/详情） |
| 审批工作台 | 我的待办列表 + 通过/驳回（驳回带意见） |
| 出纳付款 | 批次列表 + 新建批次 + 确认 + 执行付款（模拟银行）+ 明细查看 |
| 报表看板 | 报销统计（按状态）、付款进度、预算执行率（进度条） |

工程要点：
- `src/api.js`：axios 封装（Bearer Token 注入、401 跳登录、业务码统一提示）+ 各域 API
- `src/router.js`：hash 路由 + 未登录守卫
- `vite.config.js`：dev（5173）/ preview（4173）双代理 `/api → 127.0.0.1:18080`
- 构建：`npm run build` → dist/

## 3. 部署说明

```bash
cd fssc-web
npm install && npm run build     # 构建
npm run preview                  # 预览（4173，含 /api 代理）
# 生产：dist/ 交由 Nginx 托管，/api 反向代理到后端
```

演示账号：
- 租户：DEMO1 / alice / 123456（租户管理员，全权限）
