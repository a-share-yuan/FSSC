# 系统级可靠性增强（P0）

> 对应主需求文档第 12 域《系统级可靠性增强（P0）》。
> 目标：解决财务长链路（单据→审批→凭证→付款→核销）的一致性与合规性风险，上线前必做。
> 状态： 已实现（2026-08-13）

## 12.1 长链路一致性对账

### 业务说明

报销/借款/付款单据经历 提交 → 审批（Flowable）→ 生成凭证 → 付款/核销 的跨表长链路，任一环节事件丢失或异常中断都可能导致单据状态与金额不一致。提供定时对账任务自动核对，不一致项进入异常清单人工处理。

### 核对规则

- **核心恒等式**：`exp_bill.total_amount = 凭证借贷合计 = paid_amount(已付) + 未付`
- 对账口径（按单据）：
  1. 凭证核对：单据关联的凭证（op_voucher / op_voucher_line）借贷方合计 == 单据总额
  2. 付款核对：付款记录（exp_bill_payment）已付累计 == 单据 paid_amount，且 ≤ 单据总额
  3. 状态核对：单据终态（APPROVED/PAID）应有对应凭证与付款记录
- 命中任一规则不符 → 生成对账异常记录

## 12.2 金额防篡改

### 业务说明

单据从提交到审批执行期间，金额/收款账户等关键字段必须可验证未被篡改。提交时生成校验和，审批通过/付款执行时校验。

### 规则

- 校验字段：total_amount、paid_amount、payee_name、payee_account（按单据类型取实际关键字段）
- 生成时机：单据提交（submit）时计算 SHA-256 存入 `exp_bill.amount_checksum`
- 校验时机：审批通过（ExpenseWfEventListener）与付款执行前
- 命中失败：拦截并记审计，审批通过事件记录差异

### 表/字段

- `exp_bill` 增加 `amount_checksum varchar(64)`（提交时写入）
- 辅助方法：`ChecksumUtil.sha256(fields...)`；`verify(bill)` 返回是否一致

## 12.4 幂等与并发控制（P1）

### 业务说明
预算占用/核销、付款执行是高并发写点，必须防止并发超占与重复付款。

### 预算占用并发锁
- `bg_budget_item`（预算科目）按预算期间+科目维度加行级锁 `SELECT ... FOR UPDATE`
- BudgetService.occupy/release/deduct 同一科目串行化；占用流水 bg_occupy 只增不改
- 恒等式：可用 = total + adjust - occupy - used

### 付款幂等
- `op_pay_batch` 批次号唯一；`exp_bill_payment` 付款执行前校验 pay_status 未 PAID
- 执行方法幂等：同批次同明细重复调用不产生第二次付款

## 12.5 Flowable 历史数据归档（P1）

### 业务说明
ACT_HI_* 历史表只增不删，随单据量线性增长，需配置化清理。

### 清理任务
- 配置：`fssc.wf.history-retention-months`（默认 6 个月）
- 定时清理：删除结束时间超过保留期的 ACT_HI_* 记录（按 END_TIME_）
- 业务侧 wf_instance/wf_task_history 不清理（单据追溯依赖），仅清引擎历史表

## 12.6 主数据缓存分层（P1）

### 业务说明
公司/科目/费用类型/字典/汇率等主数据高频读低频写，加缓存降低 DB 压力。

### 实现
- 轻量内存缓存（ConcurrentHashMap + TTL），不引入外部缓存组件（当前单机部署）
- 变更（增删改/状态切换）主动失效；读取回源 DB 兜底
- 缓存项：md_company、md_subject、md_expense_item、sys_dict_data、md_exchange_rate

---

## 非功能要求
- 预算行锁仅对预算科目维度，避免锁粒度太大影响并发
- 归档清理仅操作 ACT_HI_*，不影响在途流程（ACT_RU_*）
- 缓存 TTL 默认 5 分钟，变更失效即时生效

## 12.7 银企直连对账（P2）

### 业务说明
银行流水与付款记录自动勾对，未勾对进入待核清单。

### 勾对规则
- 匹配键：付款记录 pay_serial_no + 金额 + 银行账号 ↔ 银行流水 serial_no + 金额 + 账号

- 页面：共享运营 → 银行流水 → 勾对状态列 + 未勾对清单；支持手动勾对/标记

## 12.8 月末关账控制（P2）

### 业务说明
会计期间关账后锁定凭证操作；凭证断号检测。

### 期间锁定
- sys_period（会计期间）加 `closed` 状态：CLOSED 后该期间凭证新增/修改/删除被拦截
- 关账/反关账权限 `period:close`；操作记审计（audit_trail）
- 凭证服务（VoucherService）新增/更新前校验期间状态

### 断号检测
- 按 租户+期间+凭证字 统计凭证号：重复/跳跃给出清单
- 接口：GET /tenant/voucher/gap-check?period=202608

## 12.10 存储设计升级（P0 落地）

### 分层逻辑 Key
`{zone}/{tenantId}/{bizType}/{yyyyMM}/{billId|NOBILL}/{uuid}.{ext}`；内部名 UUID 随机串，不用原始中文名。

### 三区隔离
- TEMP 临时（草稿）/ BUSINESS 业务正式（审批中）/ ARCHIVE 归档（已归档）
- sys_file.storage_zone 落库；FileService.moveZone(fileId, zone) 物理迁移 + 更新路径/区域（同区幂等）

### 配置化
```yaml
fssc:
  file:
    local-root: ./data/files
    zones: { temp: temp, business: business, archive: archive }
```

## 12.11 大表按月分区（阶段一容量优化）

### 已分区（5 张，seed-p61）

- 重建→拷贝→行数校验→换名→删旧；时间查询分区裁剪实测 `partitions: p202608` 单分区命中

### 不分区表

### 维护
- 新月份：`ALTER TABLE t ADD PARTITION (PARTITION p202801 VALUES LESS THAN ('2028-02-01'))`
