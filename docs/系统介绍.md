# 系统介绍

## 1. 一句话定位

FSSC 是一套**多租户 SaaS 架构的集团财务共享服务平台**：把集团企业分散在各分子公司的
费用报销、应收应付、总账核算、资金结算、影像档案等财务作业，集中到"共享中心"统一处理，
用可配置的流程引擎驱动单据在全链路中流转，最终自动生成总账凭证。

## 2. 业务场景

假设一家集团有 20 家分子公司、每天 3,000 张报销单。没有共享中心时：

- 每家公司一套账、一套流程，集团看不出统一口径；
- 审批靠人催，超时无人管；
- 发票真伪靠肉眼，凭证靠手工录；
- 档案分散，审计取证难。

FSSC 把这些环节串成一条线：

```
员工提单(App/Web)
   │
   ▼
预算控制 ──► 合规预检 ──► 多级审批(Flowable) ──► 共享中心作业(派工/排班)
   │                                                      │
   ▼                                                      ▼
出纳付款 ◄── 资金计划/批次 ◄── 结算单(三单匹配) ◄── 发票查验/OCR
   │
   ▼
自动生成总账凭证 ──► 月结 ──► 报表 ◄──► 影像归档(全程可联查)
```

## 3. 用户角色

| 角色 | 典型工作 | 主要界面 |
|---|---|---|
| 普通员工 | 提单、查看进度、补充材料 | 我的工作台、费用报销 |
| 部门领导 | 审批、驳回、转办 | 待办中心、审批单据 |
| 共享中心作业员 | 审核、派工、质检、装订 | 共享作业控制台、作业排班 |
| 资金/出纳 | 付款批次、银行对账、票据 | 资金管理、票据管理 |
| 总账会计 | 凭证复核、月结、结转 | 总账、期末处理 |
| 系统管理员 | 流程配置、权限、主数据 | 流程设计器、系统管理 |

## 4. 与 ERP / OA 的边界

| | FSSC | 传统 ERP | 传统 OA |
|---|---|---|---|
| 核心对象 | 单据的全生命周期流转 | 账务与物料 | 行政审批 |
| 流程 | 可视化 BPMN，业务人员可改 | 固定内置 | 表单流 |
| 多租户 | 一套系统服务多企业 | 每企业一套部署 | 每企业一套 |
| 财务深度 | 预算/合规/发票/凭证/月结 | 最深 | 无 |
| 开放性 | Apache-2.0 全源码 | 商业授权 | 商业授权 |

FSSC 不与 ERP 抢"记账"的深度，而是把**共享中心的作业过程**管起来：谁在什么时间
做了什么、单据现在在哪、为什么被拦下——这些是通用 ERP 不管、而共享中心最需要的。

## 6. 技术栈

- **后端**：JDK 26 / Spring Boot 4.1 / MyBatis-Plus 3.5.9 / Flowable 8.0.0 /
  MySQL 8 / jjwt / springdoc-openapi / Lombok
- **前端**：Vue 3.5 / Vite 6 / Element Plus / Pinia / bpmn-js 16.5 / ECharts
- **工程**：Maven 多模块（fssc-common + fssc-start）、npm、Docker、K8s 样例
