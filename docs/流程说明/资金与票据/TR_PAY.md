## 3. 分支与条件

**从「支付方式分档」（排他网关（分支））出发 3 条分支**

- → 「付款指令编制【资金专员】」，条件：默认流／无条件
- → 「票据业务登记【资金专员】」：票据档（背书/贴现/托收），条件 `${billType == 'TR_BILL'}`
- → 「失败原因核查与重试【资金专员】」：支付失败处理档，条件 `${billType == 'TR_PAY_FAIL'}`

## 6. 阅读提示

- 角色码是**流程定义里的原文**（如 `DEPT_MANAGER`、`FSSC_AUDITOR`），对应到哪个岗位、哪个人由运行期的角色配置与汇报线决定，本文不猜测；
- 「金额不足／其他」这类回退分支表示网关条件不满足时**退回上一档审批链**，不是流程结束；
- 条件表达式里的变量由提单或前置服务任务写入，字段口径见 `fssc/docs/data-model.md`；
- 图上个别框整体下移＝设计器原样里框体重叠（如 FA_ADD 的 FC_4 与 FK_4/FK_5 交 125x30 像素），为可读推开，不改节点与连线；
- 环节级业务叙述（这一步在做什么、落在哪张表）见同目录上层的 `业务流程-<域>.md`。
