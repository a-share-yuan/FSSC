# FSSC 接口变更日志

> 维度9 任务 DOC-04 ｜ 按版本记录接口新增/变更/废弃；离线文档用 `scripts/export-api-doc.sh` 导出

## v1.0.1 (2026-09-16)

### 新增
- `POST /api/auth/refresh` — Token 滑动续期（旧 Token 入黑名单防重放，维度4 SEC-05）
### 变更
- 全部写操作（POST/PUT/DELETE/PATCH）增加 Origin/Referer 同源校验（CSRF 纵深防御，维度4 SEC-02）
- 全部 /api/* 响应新增安全头：Content-Security-Policy / X-Content-Type-Options / X-Frame-Options / Referrer-Policy（维度4 SEC-03）
- 登录/资料接口返回的 perms 集合：逗号多码菜单已拆分为独立权限码（维度10 任务10-7，前端按钮权限匹配修复）
### 配置
- `fssc.cors.allowed-origin-patterns`：CORS 白名单配置化（默认 `*` 仅供开发）
- `fssc.security.allowed-origins`：Origin 校验额外白名单
- `fssc.bank.gateway=http`：启用 HttpBankGateway 真实银企直联（默认 mock）
- `notify.sms.enabled` / `notify.sms.provider`：短信通知渠道（维度7 EXT-03）
