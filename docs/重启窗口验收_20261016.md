## 2. 根因：重启了，但没生效

00:12 观察到 8089 已是新进程（PID 8096），但新端点仍返回：

```
{"code":404,"msg":"端点不存在：GET /api/tenant/system/dict/builtin/data/list（本系统未登记该路径…）"}
```

原因链：

1. 运行中的 jar 构建于 **10-15 12:55**，而 `TenantDictController` / `DictService` / `SysDictType`
   改动于 **23:41~23:44** ⇒ 代码没进包。
2. 服务在跑时 `mvn package` 必失败：spring-boot repackage 要 rename `fssc-server.jar`，
   被进程占用 → `Unable to rename`（WinError 32）。
3. 停服后第一次打包仍打出**假新包**：我用 `cp` 恢复备份 jar 刷新了 mtime，
   maven-jar-plugin 判「jar 比 classes 新」→ 跳过重建，repackage 只是重压旧内容
   （jar 内 class 仍停在 12:50，不含 `builtin/data/list`）。
4. 修正：停服 → `os.rename` 移走旧 jar → `mvn -o package -DskipTests` → 校验通过
   （class ts = 10-15 23:44，字节中可 grep 到 `builtin/data/list`）。
