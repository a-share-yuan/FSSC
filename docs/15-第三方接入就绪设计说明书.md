# 15-第三方接入就绪设计说明书（P13）

> 阶段：P13 真实银企直联/真实 OCR 接入就绪 （架构可插拔 + 配置开关）
> 原则：真实接入依赖外部凭据（腾讯云 AK/SK、银行网关），当前环境不伪造联线；
> 提供 Provider 架构 + 配置开关，配好凭据即切换到真实实现。

---

## 1. 银企直联（BankGateway）

```
PayBatchService.execute
  → BankGateway.submitBatch(batchNo, items)      // 业务只依赖接口
      ├── DefaultBankGateway（@Primary 默认）：模拟成功 + 生成流水号（离线可跑）
      └── HttpBankGateway（生产）：对接银行 HTTP 银企直联（认证/签名/报文转换在网关内封装）
```

- `BankGateway` 接口 + `BankResult`（success/流水号列表/响应原文/失败原因）
- `PayItem` record：收款人/开户行/账号/金额/附言
- 银行失败 → 抛业务异常，批次不置 PAID；流水号按提交顺序回写明细 bank_serial
- 配置：`fssc.bank.gateway: default`（新增实现后切换）

## 2. 真实 OCR（OcrProvider 可插拔 + 配置开关）

```
OcrService.recognizeBatch → OcrProvider.recognize(image, fileId)
  ├── MockOcrProvider（@Primary，provider=mock 默认）：确定性数据演示
  └── TencentOcrProvider（@ConditionalOnProperty fssc.ocr.provider=tencent）
        ├── 未配 SecretId/SecretKey：启动告警
        └── 已配置：启用（TODO 接入点：OCRClient + VatInvoiceOCR → OcrResult）
```

- 腾讯云接入点注释完整（引入 SDK、构造 Client、VatInvoiceOCR、Base64 传图、映射价税分离）
- 配置：`fssc.ocr.provider: mock|tencent` + `fssc.ocr.tencent.secret-id/key/region`

## 3. 验证报告（默认路径实测）

| 用例 | 结果 |
|---|---|
| OCR mock 路径（上传→识别→发票入库） |  生成 1 张 |
| 付款执行走 BankGateway |  明细 SUCCESS + bankResp「模拟银行处理成功，共 1 笔」 |
| 启动无腾讯云配置 |  不加载 TencentOcrProvider（条件注解），无异常 |
| 全量冒烟回归 |  verify-demo.sh 全绿 |

## 4. 上线切换清单

1. 腾讯云 OCR：申请 SecretId/SecretKey → `fssc.ocr.provider=tencent` + 填凭据 → 实现 TencentOcrProvider 识别映射
2. 银企直联：与银行签约拿网关地址/证书 → 新增 `HttpBankGateway`（@Primary）实现报文与签名 → `fssc.bank.gateway=http`
3. 回归：批次执行失败路径（银行拒绝 → 批次不 PAID、明细 FAILED + failReason）
