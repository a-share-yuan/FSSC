# 可视化流程设计器功能用例文档（财务共享专用）

## 1 概述

本文档针对**财务共享系统可视化流程设计器**提供完整功能用例，支撑费用报销、借款、对公付款、还款、费用申请等财务单据审批流程的可视化拖拽建模、条件配置、权限路由、发布管理。本用例面向实施人员、流程管理员，用于后台流程配置，不面向普通员工。

**参与者**：流程管理员、系统实施管理员

**适用模块**：费用报销、借款申请、对公付款、费用申请、还款等全部财务共享审批流程

## 2 用例清单

包含流程设计器全部核心能力，贴合财务共享业务（金额分级审批、岗位路由、分支网关、子流程复用、版本管理）

1. UC01：新建空白业务流程（绑定单据类型）

2. UC02：拖拽流程节点、可视化画布编辑

3. UC03：配置人工审批节点（岗位/角色/人员、审批策略）

4. UC04：配置金额/条件分支网关（财务核心）

5. UC05：配置系统自动执行节点

6. UC06：流程连线与流转条件配置

7. UC07：流程全局参数配置（生效组织、撤回规则、驳回规则）

8. UC08：流程合法性校验（语法/逻辑校验）

9. UC09：流程保存、版本发布、版本管理

10. UC10：流程预览与模拟调试运行

11. UC11：流程导入导出、备份复用

12. UC12：子流程复用配置（共享审核通用流程）

## 3 详细用例说明

### UC01 新建空白业务流程（绑定单据类型）

**用例名称**：新建空白业务流程

**前置条件**：管理员拥有流程设计权限

**后置条件**：生成空白流程画布，流程绑定指定财务单据类型

**基本流程**：

1. 管理员进入流程设计器模块，点击【新建流程】

2. 输入流程名称，选择绑定单据类型：费用报销单/借款单/对公付款单/费用申请单

3. 选择流程适用组织范围（全集团/指定分子公司）

4. 系统生成带【开始节点、结束节点】的空白画布

### UC02 拖拽流程节点、可视化画布编辑

**用例名称**：可视化画布节点拖拽编辑

**前置条件**：已新建空白流程画布

**后置条件**：画布完成节点布局，流程结构成型

**基本流程**：

1. 左侧组件库拖拽节点至画布：人工审批、系统节点、条件网关、抄送、子流程

2. 支持节点移动、删除、批量多选、复制粘贴

3. 支持画布缩放、自适应布局、自动对齐、等距排版

4. 区分节点颜色：业务审批节点、共享审批节点、系统自动节点、判断网关

**业务价值**：直观区分业务端审批、财务共享端审批，满足财务共享可视化管控要求

### UC03 配置人工审批节点（岗位/角色路由）

**用例名称**：人工审批节点属性配置

**前置条件**：画布已添加人工审批节点

**后置条件**：节点审批人、审批规则配置完成

**基本流程**：

1. 选中人工节点，右侧属性面板配置节点名称、节点类型（业务审批/共享审批）

2. 配置审批参与者规则：支持按岗位、角色、组织架构上级、部门负责人

3. 配置审批模式：单人审批、或签、会签

4. 配置审批策略：允许驳回、允许转办、允许加签

5. 开启**禁止自审批**（高管单据防自审）

6. 配置节点超时提醒规则

**财务共享核心场景**：可配置【共享初审岗、共享财务经理、共享资金岗】专属岗位路由

### UC04 配置金额/条件分支网关（财务核心）

**用例名称**：条件网关分支规则配置

**前置条件**：画布已添加排他网关节点

**后置条件**：流程可根据单据字段自动路由不同审批节点

**基本流程**：

1. 选中网关节点，进入条件配置

2. 可视化点选表单字段：单据金额、费用类型、是否超标、单据类型

3. 配置分支条件，示例：
1\. 金额≤5000：跳过经理复核
        
2\. 金额\>5000：进入共享经理复核
        
3\. 业务招待费：强制分管领导审批
      

4. 支持多条件组合（and/or）

**核心价值**：实现财务共享**金额分级审批、风险差异化审批**

### UC05 配置系统自动执行节点

**用例名称**：系统自动节点配置

**前置条件**：画布已添加系统节点

**后置条件**：流程可自动执行财务共享预设动作

**基本流程**：

1. 选择系统执行动作：发票验真查重、预算校验、借款逾期校验、冲销借款、推送付款、生成凭证、电子归档

2. 配置执行失败策略：终止流程/重试/人工干预

### UC06 流程连线与流转条件配置

**用例名称**：节点连线与分支条件配置

**前置条件**：画布存在多节点、多网关

**后置条件**：完整闭环流程链路成型

**基本流程**：

1. 节点之间拖拽连线形成流转链路

2. 对网关出口连线分别配置不同分支条件

3. 确保所有分支有终点、无死循环

### UC07 流程全局参数配置

**用例名称**：流程全局规则配置

**前置条件**：流程画布基本完成

**后置条件**：流程整体规则生效

**基本流程**：

1. 配置流程允许撤回、驳回策略（驳回至发起人/驳回至上一节点）

2. 配置是否开启代理审批

3. 配置流程生效组织、排除组织

4. 配置全局阈值变量（大额金额阈值统一维护）

### UC08 流程合法性校验

**用例名称**：流程语法与逻辑校验

**前置条件**：流程编辑完成

**后置条件**：校验通过可发布，校验失败提示具体问题

**基本流程**：

1. 点击【流程校验】

2. 系统自动检查：缺失开始/结束、分支条件不全、节点未配置审批人、死循环、配置错误

3. 输出校验结果与修改建议

### UC09 流程保存、版本发布、版本管理

**用例名称**：流程保存与版本发布

**前置条件**：流程校验通过

**后置条件**：新版本流程正式生效，新单据启用新流程

**基本流程**：

1. 保存草稿（临时保存不生效）

2. 点击发布，生成新版本号

3. 存量在途单据继续走旧版本，新单据执行新版本

4. 支持查看历史版本、版本对比、版本回滚

### UC10 流程预览与模拟调试运行

**用例名称**：流程模拟调试

**前置条件**：流程已保存

**后置条件**：验证流程路由准确性

**基本流程**：

1. 点击【模拟运行】

2. 输入模拟单据数据：金额、费用类型、是否超标

3. 系统自动走完流程，展示节点路由轨迹

4. 验证大额/小额分支、共享节点跳转是否正确

**价值**：无需建真实单据即可测试财务分级审批逻辑

### UC11 流程导入导出、备份复用

**用例名称**：流程定义导入导出

**前置条件**：流程已保存

**后置条件**：实现流程跨环境复用、备份

**基本流程**：

1. 导出流程定义文件，用于备份、迁移环境

2. 导入已有流程模板，快速复用集团标准报销流程

### UC12 子流程复用配置

**用例名称**：子流程封装与复用

**前置条件**：已存在通用子流程（财务共享审核子流程）

**后置条件**：主流程成功引用通用共享审核流程

**基本流程**：

1. 将【共享初审\+共享复核\+资金审批】封装为公共子流程

2. 报销、借款、对公付款流程直接引用该子流程

3. 子流程统一更新，所有引用流程同步生效

**财务共享核心价值**：统一共享审核标准，杜绝各单据流程不一致

## 4 非功能需求

- **可视化友好**：节点分层清晰、业务/共享节点颜色区分、路由轨迹直观

- **可配置化**：全部财务规则可视化配置，无需代码开发

- **稳定性**：发布不影响在途单据，版本隔离

- **可追溯**：所有修改、发布、版本记录日志留存

- **财务适配性**：原生支持金额分级、岗位路由、防自审、子流程复用
